ShardScript is a custom embedded programming language and virtual machine designed for host applications that need a safe, sandboxed scripting layer with C-style syntax and modern conveniences such as generics, async/await, and native interop.

Use the guides below to install the toolchain, learn the language, explore the standard library, and build native `.shard.cpp` libraries that extend the VM.
