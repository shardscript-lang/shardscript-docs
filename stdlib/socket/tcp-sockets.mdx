title: TCP Sockets

## Summary

  The `shard.socket` library exposes the `Socket` and
  `SocketStream` classes in the `net` namespace for IPv4 TCP
  networking. `Socket` provides low-level connect, listen, accept, and string-oriented
  send/receive operations, while `SocketStream` wraps a connected socket in the
  `io` stream interfaces for byte-oriented asynchronous I/O.

## Syntax

  Import the namespace with `using net;`. Both classes are reference types that implement
  `IDisposable` and should be disposed after use.

// socket_import.shard
```csharp
using stdio;
using net;

namespace demo;

public static func Main() -> void
{
    // Low-level string-oriented socket.
    client: Socket = new Socket();
    defer client.Dispose();

    // Byte-oriented stream wrapper.
    stream: SocketStream = new SocketStream(client);
    defer stream.Dispose();
}
```

## Parameters / Arguments

  **Socket parameters**

| Parameter | Type | Description |
| --- | --- | ---
| `ip` | string | An IPv4 address in dotted-quad notation, such as "127.0.0.1". For Bind, an empty string or "0.0.0.0" binds all local interfaces. |
| `port` | int | The TCP port number. Values outside the 0-65535 range are rejected by the underlying operating system. |
| `data` | string | The text payload to send. The implementation transmits the string as UTF-16 wide characters. |
| `bufferSize` | int | The maximum number of wide characters to receive. Must be greater than zero or Receive returns an empty string. |
| `backlog` | int | The maximum length of the pending connection queue. Passing -1 lets the platform choose a default. |

  **SocketStream parameters**

| Parameter | Type | Description |
| --- | --- | ---
| `socket` | Socket | An existing connected or accepted Socket whose handle is adopted by the stream. |
| `buffer` | byte[] | The byte array that receives or supplies data. |
| `offset` | int | The zero-based index in buffer where the operation begins. Must be non-negative. |
| `count` | int | The number of bytes to read or write. Must be non-negative and fit within the buffer bounds. |
| `cancellationToken` | CancellationToken | A token obtained from CancellationTokenSource. When canceled, the async operation faults with an Operation canceled error. |

## Returns

| Member | Return Type | Description |
| --- | --- | ---
| `Socket.Connect` | bool | true when the connection succeeds; false when the address is invalid or the connection is refused. |
| `Socket.Send` | int | The number of bytes transmitted, or -1 if the socket handle is invalid. The count is in bytes, not characters. |
| `Socket.Bind` | bool | true when the local endpoint is bound successfully. |
| `Socket.Listen` | bool | true when the socket enters the listening state. |
| `Socket.Accept` | Socket | A new Socket representing the accepted client connection. |
| `Socket.AcceptAsync` | ValueTask&lt;Socket&gt; | An awaitable Socket for the next incoming connection. |
| `Socket.Receive` | string | The received wide-character string, or an empty string if the socket is closed or no data is available. |
| `SocketStream.Connect` | bool | true when the connection succeeds; otherwise a runtime exception is thrown. |
| `SocketStream.Read` | int | The number of bytes copied into buffer. Zero indicates end-of-stream. |
| `SocketStream.ReadAsync` | ValueTask&lt;int&gt; | An awaitable byte count. Zero indicates end-of-stream. |
| `SocketStream.Write / WriteAsync` | void / Task | Completes after the requested bytes are sent or an error is reported. |
| `SocketStream.Flush / FlushAsync` | void / Task | No operation; TCP sends data immediately. |
| `Close / Dispose` | void | Releases the native socket handle. Subsequent operations fail or throw. |

## Exceptions / Errors

  - **Namespace import required** — The  `net` namespace must be imported with `using net;` before referencing `Socket` or `SocketStream`.
  - **Socket creation failure** — Constructing  `new Socket()` or `new SocketStream()` throws a runtime exception when the underlying `socket(AF_INET, SOCK_STREAM, IPPROTO_TCP)` call fails or the network subsystem cannot be initialized.
  - **Invalid server socket handle** —  `Socket.Accept()` and `Socket.AcceptAsync()` throw when called on a socket that has not been bound and listened, or whose handle has already been closed.
  - **Invalid IP address** —  `SocketStream.Connect` throws when `ip` cannot be parsed as an IPv4 address. `Socket.Connect` returns `false` instead.
  - **Receive on invalid socket** —  `Socket.Receive` returns an empty string when the handle is invalid or when the peer has closed the connection; it does not throw.
  - **Read from a closed SocketStream** —  `SocketStream.Read` and `ReadAsync` throw when the stream has been disposed or closed.
  - **Negative offset or count** —  `SocketStream.Read` and `SocketStream.Write` reject negative  `offset` or `count` values.
  - **Socket send/receive failure** —  `SocketStream.Write` and `SocketStream.Read` throw when the underlying native send or recv call reports an error.
  - **Operation canceled** — The cancellation-aware async overloads on `SocketStream` fault with an `Operation canceled` error when the provided `CancellationToken` is canceled before or during the operation.

## Remarks

  **IPv4 TCP only.** The current implementation creates sockets with
  `AF_INET`, `SOCK_STREAM`, and `IPPROTO_TCP`. IPv6
  addresses, UDP datagrams, and Unix domain sockets are not supported by this library.

  **Wide-character string transport.** `Socket.Send` transmits each character as a
  platform wide character (UTF-16LE on Windows, typically 32-bit on Linux). The byte count returned by
  `Send` is therefore `data.Length * sizeof(wchar_t)`, not the character
  count. `Receive` reads raw bytes and reconstructs a string from complete wide characters. Use
  `SocketStream` when you need portable byte-oriented transport and control over encoding.

  **Bind any local interface.** For server sockets, pass `"0.0.0.0"` or an empty
  string to `Bind` to listen on all available IPv4 interfaces. A specific address such as
  `"127.0.0.1"` restricts the listener to the loopback interface.

  **Backlog behavior.** `Listen(backlog)` forwards the backlog value directly to
  the operating system. A negative value such as `-1` is accepted by the implementation and
  resolved to a platform default, but the exact limit depends on the host OS.

  **SocketStream is a thin stream adapter.** `SocketStream` implements
  `io.IReadableStream`, `io.IWritableStream`, and
  `IDisposable`. It does not buffer, seek, or expose `Position` or
  `Length`. `Flush` and `FlushAsync` are no-ops
  because TCP sends data immediately.

  **Asynchronous operations run on the thread pool.**
  `Socket.AcceptAsync` and the `SocketStream` async methods schedule the
  blocking native call on a background thread and resume the awaiting ShardScript task on completion. This keeps the
  VM event loop responsive while waiting for network I/O.

  **End-of-stream detection.** `SocketStream.Read` and
  `ReadAsync` return `0` when the peer gracefully closes the connection.
  A loop that reads until EOF must treat `0` as termination, not as an error.

  **Dispose is idempotent.** Calling `Close()` or
  `Dispose()` more than once on a `Socket` or
  `SocketStream` is safe. Both methods close the native handle and mark the object as closed.
  Because both classes implement `IDisposable`, the `defer` statement can
  be used for deterministic cleanup.

<Info>
Prefer `SocketStream` for new code. It interoperates with generic helpers written against
  `io.IReadableStream` and `io.IWritableStream`, supports cancellation
  tokens, and avoids the wide-character encoding quirks of the low-level `Socket.Send` /
  `Socket.Receive` API.
</Info>

<Warning title="Not implemented">
UDP sockets, IPv6, raw sockets, non-blocking polling, socket options (keep-alive, no-delay, receive buffer size),
  and DNS hostname resolution are not exposed by `shard.socket`. Connect by IPv4 address or
  resolve hostnames through a separate library before calling `Connect`.
</Warning>

## Examples

  **Simple TCP client using the low-level Socket API.**

// socket_client.shard
```csharp
using stdio;
using net;

namespace demo;

public static func Main() -> void
{
    client: Socket = new Socket();
    defer client.Dispose();

    if (!client.Connect("127.0.0.1", 6969))
    {
        println("Failed to connect to server");
        return;
    }

    sent: int = client.Send("Hello from ShardScript");
    println("Sent bytes: " + sent);
}
```

  **Simple TCP echo server using the low-level Socket API.**

// socket_server.shard
```csharp
using stdio;
using net;

namespace demo;

public static func Main() -> void
{
    server: Socket = new Socket();
    defer server.Dispose();

    if (!server.Bind("127.0.0.1", 6969))
    {
        println("Failed to bind");
        return;
    }

    if (!server.Listen(-1))
    {
        println("Failed to listen");
        return;
    }

    println("Server listening on port 6969");

    while (true)
    {
        client: Socket = server.Accept();
        if (client == null)
        {
            continue;
        }

        defer client.Dispose();

        message: string = client.Receive(1024);
        println("Received: " + message);

        // Echo the same payload back to the client.
        client.Send(message);
    }
}
```

  **Byte-oriented echo server and client with SocketStream.**

// socket_stream_echo.shard
```csharp
using stdio;
using async;
using net;
using io;

namespace demo;

public class Program
{
    public static async func RunServer(port: int, done: TaskCompletionSource<int>) -> Task
    {
        server: Socket = new Socket();
        defer server.Dispose();

        if (!server.Bind("127.0.0.1", port))
        {
            println("Failed to bind");
            throw new RuntimeException();
        }

        if (!server.Listen(1))
        {
            println("Failed to listen");
            throw new RuntimeException();
        }

        client: Socket = await server.AcceptAsync();
        defer client.Dispose();

        stream: SocketStream = new SocketStream(client);
        defer stream.Dispose();

        buffer: byte[] = [0 as byte; 64];
        read: int = await stream.ReadAsync(buffer, 0, buffer.Length);
        if (read == 0)
        {
            println("Client disconnected before sending data");
            throw new RuntimeException();
        }

        await stream.WriteAsync(buffer, 0, read);
        done.SetResult(0);
    }

    public static async func RunClient(port: int) -> Task
    {
        client: Socket = new Socket();
        defer client.Dispose();

        if (!client.Connect("127.0.0.1", port))
        {
            println("Failed to connect");
            throw new RuntimeException();
        }

        stream: SocketStream = new SocketStream(client);
        defer stream.Dispose();

        payload: byte[] = [72 as byte, 101 as byte, 108 as byte, 108 as byte, 111 as byte];
        await stream.WriteAsync(payload, 0, payload.Length);

        buffer: byte[] = [0 as byte; 64];
        read: int = await stream.ReadAsync(buffer, 0, buffer.Length);

        i: int = 0;
        while (i < read)
        {
            println(buffer[i]);
            i = i + 1;
        }
    }

    public static func Main() -> void
    {
        port: int = 17654;
        done: TaskCompletionSource<int> = new TaskCompletionSource<int>();

        serverTask: Task = RunServer(port, done);

        // Give the server time to start listening before connecting.
        Task.Wait(Task.Delay(50));

        clientTask: Task = RunClient(port);
        Task.Wait(clientTask);
        Task.Wait(serverTask);

        println("echo completed");
    }
}
```

  **Reading until end-of-stream with SocketStream.**

// socket_stream_read_all.shard
```csharp
using stdio;
using net;
using io;

namespace demo;

public static func ReadAll(stream: SocketStream) -> byte[]
{
    accumulator: MemoryStream = new MemoryStream();
    defer accumulator.Dispose();

    chunk: byte[] = [0 as byte; 256];

    while (true)
    {
        read: int = stream.Read(chunk, 0, chunk.Length);
        if (read == 0)
        {
            // The peer closed the connection; no more bytes will arrive.
            break;
        }

        accumulator.Write(chunk, 0, read);
    }

    return accumulator.ToArray();
}

public static func Main() -> void
{
    socket: Socket = new Socket();
    defer socket.Dispose();

    if (!socket.Connect("127.0.0.1", 8080))
    {
        println("Failed to connect");
        return;
    }

    stream: SocketStream = new SocketStream(socket);
    defer stream.Dispose();

    data: byte[] = ReadAll(stream);
    println("Received " + data.Length + " bytes");
}
```

  **Cancellation-aware SocketStream read.**

// socket_stream_cancellation.shard
```csharp
using stdio;
using async;
using net;

namespace demo;

public class Program
{
    public static async func RunCancellationDemo() -> Task
    {
        socket: Socket = new Socket();
        defer socket.Dispose();

        if (!socket.Connect("127.0.0.1", 8080))
        {
            println("Failed to connect");
            return;
        }

        stream: SocketStream = new SocketStream(socket);
        defer stream.Dispose();

        cts: CancellationTokenSource = new CancellationTokenSource();
        cts.CancelAfter(100);   // cancel after 100 milliseconds

        buffer: byte[] = [0 as byte; 256];

        try
        {
            read: int = await stream.ReadAsync(buffer, 0, buffer.Length, cts.Token);
            println("Read " + read + " bytes");
        }
        catch (ex: RuntimeException)
        {
            println("Read was canceled or failed: " + ex.message);
        }

        cts.Dispose();
    }

    public static func Main() -> void
    {
        task: Task = RunCancellationDemo();
        Task.Wait(task);
    }
}
```

  **Common mistake: assuming Receive returns null on disconnect.**

// socket_receive_mistake.shard
```csharp
using stdio;
using net;

namespace demo;

public static func Main() -> void
{
    socket: Socket = new Socket();
    defer socket.Dispose();

    if (!socket.Connect("127.0.0.1", 8080))
    {
        println("Failed to connect");
        return;
    }

    // WRONG: Socket.Receive never returns null.
    // if (socket.Receive(1024) == null) { ... }

    // CORRECT: test for the empty string.
    response: string = socket.Receive(1024);
    if (response == "")
    {
        println("Peer closed the connection or no data arrived");
    }
    else
    {
        println(response);
    }
}
```

  **Common mistake: forgetting to dispose accepted clients.**

// socket_dispose_client.shard
```csharp
using stdio;
using net;

namespace demo;

public static func Main() -> void
{
    server: Socket = new Socket();
    defer server.Dispose();

    if (!server.Bind("127.0.0.1", 6969) || !server.Listen(-1))
    {
        println("Server setup failed");
        return;
    }

    while (true)
    {
        client: Socket = server.Accept();

        // CORRECT: dispose each accepted client to release the native handle.
        defer client.Dispose();

        msg: string = client.Receive(1024);
        println(msg);
    }
}
```
