---
title: Directory & DirectoryInfo
---

## Summary

  The `filesystem` namespace provides two directory abstractions:
  `Directory`, a static utility class for existence checks and
  creation by path, and `DirectoryInfo`, an instance-based wrapper
  around a directory path that supports path composition and stateful existence checks.

## Syntax

  All members live in the `filesystem` namespace. Add
  `using filesystem;` at the top of a ShardScript file.

// directory_overview.shard
```csharp
using stdio;
using filesystem;

namespace demo;

public static func Main() -> void
{
    // Static Directory API.
    exists: bool = Directory.Exists("D:/data");
    info: DirectoryInfo = Directory.Create("D:/data/temp");

    // DirectoryInfo instance API.
    println(info.FullName);
    println(info.Exists);

    // Path composition.
    sub: DirectoryInfo = info / "subfolder";
    file: FileInfo = info / "log.txt";
}
```

## Parameters / Arguments

The static `Directory` class accepts the following inputs:

| Method | Parameter | Type | Description |
| --- | --- | --- | ---
| `Exists(path)` | path | string | The directory path to test. |
| `Create(path)` | path | string | The directory path to create. Missing parents are created automatically. |
| `Delete(path)` | path | string | The directory path to delete. The directory must be empty. |

The `DirectoryInfo` constructor and members accept the following inputs:

| Member | Parameter | Type | Description |
| --- | --- | --- | ---
| `new DirectoryInfo(fullPath)` | fullPath | string | The absolute or relative directory path to wrap. |
| `DirectoryInfo / segment` | segment | string | A relative directory or file name to append. |
| `Create()` | — | — | Creates the directory on disk, including any missing parents. |
| `Delete()` | — | — | Deletes the directory and all of its contents recursively. |

<Warning title="Planned but not implemented">
`Directory.GetFiles(path)`,
  `Directory.GetDirectories(path)`, and
  `Directory.GetCurrentDirectory()` are planned for a future release.
  They do not currently exist in the `shard.io` native implementation.
  To enumerate content today, store known names in a `string[]` and
  join them with the directory path manually.
</Warning>

## Returns

| Member | Return Type | Description |
| --- | --- | ---
| `Directory.Exists(path)` | bool | True if the path exists; false otherwise. |
| `Directory.Create(path)` | DirectoryInfo | A DirectoryInfo wrapping the newly created or existing directory. |
| `Directory.Delete(path)` | void | No return value. |
| `DirectoryInfo.FullName` | string | The full path used to construct the instance. |
| `DirectoryInfo.Name` | string | The last path component (the directory name). |
| `DirectoryInfo.Exists` | bool | True if the path refers to an existing directory. |
| `DirectoryInfo.Create()` | void | No return value. |
| `DirectoryInfo.Delete()` | void | No return value. |
| `DirectoryInfo / string` | DirectoryInfo or FileInfo | A new instance with the joined path. |

## Exceptions / Errors

  - **Create failure** —  `Directory.Create` and  `DirectoryInfo.Create` throw a runtime exception if the directory tree cannot be created (for example, because a file with the same name already exists or because the caller lacks permission).
  - **Delete failure** —  `Directory.Delete(path)` throws if the directory does not exist or is not empty. `DirectoryInfo.Delete()` throws if the recursive removal fails.
  - **Path does not exist** —  `DirectoryInfo.Exists` simply returns false; it never throws for a missing path.
  - **Invalid path composition** — The  `/` operator creates a new path object without checking the disk. Errors surface only when the resulting path is used with a method that touches the file system.

## Remarks

  **Static versus instance design.** `Directory` is a
  static class (`LINK_STATIC`). It is never instantiated and every
  method resolves at compile time to `CALLSTATICMETHODSYMBOL`.
  `DirectoryInfo` is an instance class: it stores the wrapped path in
  the `FullName` backing field and allocates a new object for every
  path composition.

  **Native backing.** The implementation in
  `system/filesystem.shard.cpp` delegates to the C++ standard library's
  `std::filesystem` facilities. `Exists` calls
  `fs::exists`, `DirectoryInfo.Exists` calls
  `fs::is_directory`, and creation uses
  `fs::create_directories` (recursive mkdir-p semantics).

  **Path composition.** `DirectoryInfo / string` is
  overloaded. When the target type is `DirectoryInfo`, the segment is
  appended as a subdirectory. When the target type is `FileInfo`, the
  segment is treated as a file name and a `FileInfo` is produced. The
  operator never touches the disk; it only manipulates the path string.

  **Delete semantics differ.** `Directory.Delete(path)`
  requires the directory to be empty and uses `fs::remove`.
  `DirectoryInfo.Delete()` removes the directory tree recursively via
  `fs::remove_all`. Choose the static method for a safe, empty-only
  removal and the instance method when you intend to wipe nested contents.

<Info>
The native callback behind `Directory.Create` is named
  `shard_directory_CreateDirectory`, but the public ShardScript member
  is `Create`. Use `Directory.Create(path)`, not
  `Directory.CreateDirectory(path)`.
</Info>

## Examples

  **Creating and inspecting a directory.**

// directory_create_inspect.shard
```csharp
using stdio;
using filesystem;

namespace demo;

public static func Main() -> void
{
    workDir: string = "D:/temp/shard_dir_demo";

    // Ensure a clean starting state.
    if (Directory.Exists(workDir))
    {
        Directory.Delete(workDir);
    }

    // Create the directory and inspect the returned DirectoryInfo.
    info: DirectoryInfo = Directory.Create(workDir);

    println(info.FullName);   // D:/temp/shard_dir_demo
    println(info.Name);       // shard_dir_demo
    println(info.Exists);     // true

    // Clean up.
    info.Delete();
    println(info.Exists);     // false
}
```

  **Path composition with DirectoryInfo.**

// directory_compose.shard
```csharp
using stdio;
using filesystem;

namespace demo;

public static func Main() -> void
{
    root: DirectoryInfo = new DirectoryInfo("D:/app");

    // Compose a subdirectory path without touching the disk.
    configDir: DirectoryInfo = root / "config";
    println(configDir.FullName);   // D:/app/config

    // Compose a file path under the directory.
    settings: FileInfo = root / "config" / "settings.json";
    println(settings.FullName);    // D:/app/config/settings.json

    // Create the directory tree and write a file.
    configDir.Create();
    File.WriteAllText(settings.FullName, " ");

    // Clean up the entire tree.
    configDir.Delete();
}
```

  **Conditional creation and safe cleanup.**

// directory_conditional.shard
```csharp
using stdio;
using filesystem;

namespace demo;

public static func EnsureWorkDirectory(path: string) -> DirectoryInfo
{
    // Create only when the path is absent.
    if (!Directory.Exists(path))
    {
        return Directory.Create(path);
    }

    return new DirectoryInfo(path);
}

public static func Main() -> void
{
    target: string = "D:/temp/shard_work";
    dir: DirectoryInfo = EnsureWorkDirectory(target);

    // The instance tracks the same path we just ensured.
    println(dir.Exists);       // true
    println(dir.FullName);     // D:/temp/shard_work

    // Safe cleanup: remove only if we actually created it in this run.
    if (dir.Exists)
    {
        dir.Delete();
    }
}
```

  **Manual enumeration for planned APIs.** Because
  `Directory.GetFiles` and
  `Directory.GetDirectories` are not yet implemented, you can join
  known names to a directory path by hand.

// directory_manual_enumerate.shard
```csharp
using stdio;
using filesystem;

namespace demo;

public static func Main() -> void
{
    baseDir: DirectoryInfo = Directory.Create("D:/temp/shard_logs");

    // Create a few files so we have something to list.
    File.WriteAllText((baseDir / "app.log").FullName, "app");
    File.WriteAllText((baseDir / "error.log").FullName, "error");

    // Stand-in for Directory.GetFiles: enumerate a known list.
    candidates: string[] = ["app.log", "error.log", "missing.log"];

    foreach (name in candidates)
    {
        file: FileInfo = baseDir / name;

        if (file.Exists)
        {
            println("found: " + file.FullName);
        }
    }

    // Clean up.
    baseDir.Delete();
}
```

<Warning title="Common mistake: treating Exists as creation guarantee">
`Directory.Exists` and `DirectoryInfo.Exists`
  test the disk at the moment of the call. Between the check and a subsequent operation, the
  directory can be deleted or created by another process. If atomicity matters, call
  `Directory.Create` directly and handle the resulting exception.
</Warning>

<Warning title="Common mistake: Directory.Delete on a non-empty directory">
`Directory.Delete(path)` requires the directory to be empty. To
  delete a tree recursively, use `DirectoryInfo.Delete()` on a
  `DirectoryInfo` instance.
</Warning>
