## Summary

  The `shard.time` library provides two value types in the `time`
  namespace: `TimeSpan` for representing a duration, and
  `DateTime` for representing an instant in time. Both are implemented as native structs,
  store their data as 64-bit tick counts, and expose factory methods, properties, arithmetic operators, and
  formatting helpers.

## Syntax

  Reference the `time` namespace with a `using` directive. The
  library is loaded automatically when a `using time;` directive is present, or it can
  be passed to the interpreter with the `-l` flag when running standalone scripts.

// time_intro.shard
```csharp
using stdio;
using time;

namespace demo;

public static func Main() -> void
{
    span: TimeSpan = TimeSpan.FromSeconds(90.0);
    println(span.TotalMinutes);

    now: DateTime = DateTime.Now;
    println(now.ToString("yyyy-MM-dd HH:mm:ss"));
}
```

## Enum DateTimeKind

| Value | Numeric value | Meaning |
| --- | --- | ---

## Struct TimeSpan

  `TimeSpan` stores a signed number of 100-nanosecond ticks. Positive and negative
  durations are supported.

| `FromMilliseconds(value)` | `value`: double | TimeSpan | Creates a TimeSpan from a number of milliseconds. |
| `FromSeconds(value)` | `value`: double | TimeSpan | Creates a TimeSpan from a number of seconds. |
| `FromMinutes(value)` | `value`: double | TimeSpan | Creates a TimeSpan from a number of minutes. |

## Struct DateTime

  `DateTime` stores an instant as a 64-bit tick count together with a
  `DateTimeKind`. One tick is 100 nanoseconds. The epoch for Unix conversions is
  1970-01-01 00:00:00 UTC.

## DateTime static factory members

| Member | Parameters | Returns | Description |
| --- | --- | --- | ---
| `Now` | none | DateTime | Static property that returns the current local time. |
| `UtcNow` | none | DateTime | Static property that returns the current UTC time. |
| `FromUnixTimeSeconds(seconds)` | `seconds`: int | DateTime | Creates a UTC DateTime from a Unix seconds timestamp. |
| `FromUnixTimeMilliseconds(milliseconds)` | `milliseconds`: int | DateTime | Creates a UTC DateTime from a Unix milliseconds timestamp. |

## DateTime properties

| Property | Type | Description |
| --- | --- | ---
| `Ticks` | int | The complete tick count. |
| `UnixTimestamp` | int | The number of whole seconds since the Unix epoch. |
| `UnixTimestampMilliseconds` | int | The number of whole milliseconds since the Unix epoch. |
| `Kind` | DateTimeKind | The kind of the DateTime: Utc, Local, or Unspecified. |
| `Year` | int | The calendar year component. |
| `Month` | int | The month component, 1-12. |
| `Day` | int | The day-of-month component, 1-31. |
| `DayOfWeek` | int | The day of week, 0-6, where 0 is Sunday. |
| `Hour` | int | The hour component, 0-23. |
| `Minute` | int | The minute component, 0-59. |
| `Second` | int | The second component, 0-59. |
| `Millisecond` | int | The millisecond component, 0-999. |
| `Date` | DateTime | A new DateTime set to midnight of the same calendar day. |

## DateTime operators

| Operator | Signature | Description |
| --- | --- | ---
| `dt + span` | DateTime + TimeSpan | Returns a DateTime advanced by the span. |
| `dt - span` | DateTime - TimeSpan | Returns a DateTime moved back by the span. |
| `a - b` | DateTime - DateTime | Returns the TimeSpan between two DateTime values. |
| `a == b` | DateTime == DateTime | Returns true if the tick counts are equal. |
| `a != b` | DateTime != DateTime | Returns true if the tick counts differ. |
| `a < b` | DateTime &lt; DateTime | Tick-count less-than comparison. |
| `a > b` | DateTime &gt; DateTime | Tick-count greater-than comparison. |
| `a <= b` | DateTime &lt;= DateTime | Tick-count less-than-or-equal comparison. |
| `a >= b` | DateTime &gt;= DateTime | Tick-count greater-than-or-equal comparison. |

## Returns

  Factory methods and operators return new `TimeSpan` or
  `DateTime` value-type instances. Properties return the corresponding primitive or
  enum value. Methods that perform arithmetic return a new instance and do not mutate the receiver.

## Exceptions / Errors

  - **Division by zero.** Dividing a  `TimeSpan` by `0.0` or dividing two spans where the divisor is zero throws a runtime exception.
  - **Invalid Unix timestamp.** Very large positive or negative Unix timestamps can produce a `DateTime` outside the range supported by the platform `time_t` conversion.
  - **Local-time ambiguity.**  `ToLocalTime` and `ToUniversalTime` rely on the host platform's local-time zone database. On hosts without valid zone data, the conversion may return the original ticks unchanged.

## Remarks

  `TimeSpan` and `DateTime` are registered as native structs, not
  classes, so they are value types inside ShardScript. Assignment and parameter passing copy the underlying
  tick fields rather than sharing a reference. Both types are immutable: every mutating-looking operation such
  as `Add` or `Negate` returns a new instance.

  The internal representation uses the same tick scale as .NET: 1 tick = 100 nanoseconds, 10 000 ticks = 1
  millisecond, and 10 000 000 ticks = 1 second. This makes conversions to and from Unix timestamps
  straightforward and avoids floating-point drift for whole-second values.

  The custom format string for `DateTime.ToString(format)` supports the following
  tokens. All other characters are copied to the output literally.

| Token | Output |
| --- | ---
| `yyyy` | Four-digit year. |
| `MM` | Two-digit month, 01-12. |
| `dd` | Two-digit day, 01-31. |
| `HH` | Two-digit 24-hour, 00-23. |
| `mm` | Two-digit minute, 00-59. |
| `ss` | Two-digit second, 00-59. |
| `fff` | Three-digit millisecond, 000-999. |

## Examples

  Create durations, perform arithmetic, and format the current local time.

// time_demo.shard
```csharp
using stdio;
using time;

namespace demo;

public static func Main() -> void
{
    span: TimeSpan = TimeSpan.FromSeconds(90.0);
    println("TotalSeconds = " + span.TotalSeconds);
    println("Minutes = " + span.Minutes);
    println("Seconds = " + span.Seconds);

    a: TimeSpan = TimeSpan.FromMinutes(10.0);
    b: TimeSpan = TimeSpan.FromMinutes(5.0);
    println("10min + 5min = " + (a + b).TotalMinutes + " min");

    scaled: TimeSpan = a * 2.0;
    println("10min * 2 = " + scaled.TotalMinutes + " min");

    now: DateTime = DateTime.Now;
    println("Now: " + now.ToString("yyyy-MM-dd HH:mm:ss"));

    tomorrow: DateTime = now + TimeSpan.FromDays(1.0);
    println("Tomorrow day: " + tomorrow.Day);

    utc: DateTime = now.ToUniversalTime();
    println("UTC year: " + utc.Year);
}
```
