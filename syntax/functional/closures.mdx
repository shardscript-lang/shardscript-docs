---
title: Closures
---

A **closure** is a lambda expression together with the variables it references from its enclosing scope. ShardScript lowers capturing lambdas into compiler-generated closure classes on the GC heap, so the lambda can safely use its captured state after the surrounding function returns.

## Introduction

  In ShardScript, functions are values. A `lambda` creates an anonymous function that can be stored in a variable, passed to another function, or returned from a method. When that lambda reads or writes a variable declared outside its own body, the combination of the lambda and the variables it uses is called a closure.

  Closures let a small piece of code carry its own environment. A filter predicate can capture a threshold value, a factory function can capture configuration, and a callback can capture the state it needs to react to an event. Because captured locals are promoted to a heap-allocated closure object, the delegate can outlive the stack frame that created it.

## What it is

  A closure has two parts:

  - **The function body** — the code inside the `lambda` expression.
  - **The captured environment** — the set of outer variables the lambda references.

  When the compiler sees a lambda reference an outer variable, it:

  1. Identifies every local variable, parameter, and `this` referenced inside the lambda but declared outside it.
  2. Creates a compiler-generated capture class containing those values as fields.
  3. Allocates an instance of that class on the GC heap at the point the lambda is created.
  4. Copies the current values of the captured locals into the capture object's fields.
  5. Rewrites the lambda's variable accesses to read from the capture object.
  6. Stores a reference to the capture object inside the delegate so the variables stay alive as long as the delegate does.

## When to use it

  Closures are the right tool when a function needs a small amount of surrounding state and you want to keep that state near the code that uses it.

  - **Callbacks and predicates** — pass a lambda to `Where`, `Select`, or any higher-order API and let it capture the comparison value.
  - **Factory functions** — return a lambda preconfigured with settings from the factory call.
  - **Event handlers** — capture the object or state the handler needs to update.
  - **Encapsulation** — hide mutable state behind a narrow functional interface.

## Remarks

  **Capture by value.** ShardScript captures the **value** of a local at the moment the lambda is created. Later changes to the original local do not affect the closure, and assignments inside the closure do not affect the outer local.

  **Readonly capture semantics.** Captured locals are read-only inside the lambda body. The lambda can read the captured variable, but it cannot reassign it. A syntax for mutable capture has not been finalized.

  **Capturing `this`.** An instance lambda that references `this` captures the enclosing instance. The capture object stores the `this` reference in a dedicated field, and the closure method reads instance members through that field.

  **Capturing loop variables.** A `foreach` or `for` loop variable can be captured. Each iteration's value is copied into the closure at the point the lambda is created, so storing multiple lambdas in a collection and invoking them later prints the value each lambda observed.

  **Non-capturing versus capturing lambdas.** A lambda that only uses its parameters and globals is a **non-capturing** lambda. A **capturing** lambda references at least one local variable, parameter, or `this` from an enclosing scope and is lowered into a closure class.

<Info title="Captures are by value">
ShardScript copies the captured value into the closure object. If you need the closure to observe later changes to an outer variable, copy the value into a heap-allocated object or pass the updated value as an argument.
</Info>

## Examples

  **Non-capturing lambda passed to a higher-order function.**

// non_capturing_lambda.shard
```csharp
using stdio;
using collections;

namespace demo;

public delegate IntFunc(a: int) -> int;

// A higher-order function that transforms each element.
static func ApplyEach(items: int[], transform: IntFunc) -> List<int>
{
    result: List<int> = new List<int>();

    foreach (item in items)
    {
        result.Add(transform(item));
    }

    return result;
}

public static func Main() -> void
{
    values: int[] = [1, 2, 3, 4];

    // This lambda does not capture any outer locals.
    doubled: List<int> = ApplyEach(values, lambda (n: int) -> int
    {
        return n * 2;
    });

    foreach (n in doubled)
    {
        println(n);
    }
}
```

  **Returning a lambda from a function.**

// returning_lambda.shard
```csharp
using stdio;

namespace demo;

public delegate IntFunc(a: int) -> int;

// Returns a lambda that captures 'factor' by value.
static func MakeMultiplier(factor: int) -> IntFunc
{
    return lambda (n: int) -> int
    {
        return n * factor;
    };
}

public static func Main() -> void
{
    triple: IntFunc = MakeMultiplier(3);
    println(triple(5));   // 15
}
```

  **Closure with a captured local.**

// capture_local.shard
```csharp
using stdio;

namespace demo;

public delegate IntFunc(a: int) -> int;

public static func Main() -> void
{
    offset: int = 10;

    // 'offset' is captured into the closure by value.
    addOffset: IntFunc = lambda (a: int) -> int
    {
        return a + offset;
    };

    println(addOffset(5));   // 15
}
```

  **Readonly capture: reading a captured value.**

// readonly_capture.shard
```csharp
using stdio;

namespace demo;

public delegate Predicate(x: int) -> bool;

static func CountWhere(items: int[], matches: Predicate) -> int
{
    count: int = 0;

    foreach (n in items)
    {
        if (matches(n))
        {
            count = count + 1;
        }
    }

    return count;
}

public static func Main() -> void
{
    threshold: int = 5;
    nums: int[] = [1, 6, 3, 9, 4];

    // The lambda captures 'threshold' as a read-only value.
    big: int = CountWhere(nums, lambda (n: int) -> bool
    {
        return n > threshold;
    });

    println(big);   // 2
}
```

  **Capture by value: later changes do not affect the closure.**

// capture_by_value.shard
```csharp
using stdio;

namespace demo;

public delegate IntFunc(a: int) -> int;

public static func Main() -> void
{
    multiplier: int = 3;

    // The closure stores the value 3.
    scale: IntFunc = lambda (n: int) -> int
    {
        return n * multiplier;
    };

    println(scale(7));   // 21

    // Changing the outer local does not affect the captured value.
    multiplier = 10;
    println(scale(7));   // 21
}
```

  **Capturing loop variables.**

// capture_loop_variable.shard
```csharp
using stdio;
using collections;

namespace demo;

public delegate VoidFunc() -> void;

public static func Main() -> void
{
    callbacks: List<VoidFunc> = new List<VoidFunc>();

    foreach (i in 0..3)
    {
        callbacks.Add(lambda () -> void
        {
            println(i);
        });
    }

    foreach (callback in callbacks)
    {
        callback();
    }
}
```

  Expected output:

```text
0
1
2
```

  **Common mistake: trying to reassign a captured local.**

// readonly_capture_mistake.shard
```csharp
using stdio;

namespace demo;

public delegate VoidFunc() -> void;

public static func Main() -> void
{
    counter: int = 0;

    // ERROR: captured locals are read-only inside the lambda.
    // increment := lambda () -> void => counter = counter + 1;

    println(counter);
}
```

  **Returning a closure that outlives its creating scope.**

// escaping_closure.shard
```csharp
using stdio;

namespace demo;

public delegate VoidFunc() -> void;

static func CreateCallback() -> VoidFunc
{
    message: string = "hello";

    return lambda () -> void
    {
        println(message);
    };
}

public static func Main() -> void
{
    callback: VoidFunc = CreateCallback();
    callback();   // hello
}
```
