---
title: Loops
---

## Summary

  ShardScript provides imperative looping constructs for repeating a block of
  code while a condition holds, scanning a sequence, or counting with a
  C-style initializer/condition/step header. The language supports
  `while`, `until`, C-style
  `for`, `foreach`, integer range
  expressions, and the `break` /
  `continue` jump statements.

## Syntax

  Every loop body is a statement block enclosed in braces. Conditions are
  written inside parentheses.

  - `while (condition) &#123; body &#125;`
  - `until (condition) &#123; body &#125;`
  - `for (initializer; condition; step) &#123; body &#125;`
  - `foreach (identifier in enumerable) &#123; body &#125;`
  - Half-open range: `lower..upper`
  - Inclusive range: `lower..&upper`
  - `break;` and `continue;`

  The condition for `while` and
  `until` must evaluate to `bool`.
  The C-style `for` header contains three statements
  separated by semicolons: an initializer that runs once, a condition checked
  before every iteration, and a step expression run after the body. A
  `foreach` loop declares an iteration variable that is
  scoped to the body and binds successive elements from any
  `IEnumerable<T>` source.

## Parameters / Arguments

| Construct | Input | Constraints |
| --- | --- | ---
| `while` | condition expression | Must evaluate to bool. |
| `until` | condition expression | Must evaluate to bool; body runs while condition is false. |
| &lt;span&gt;`for` initializer&lt;/span&gt; | variable declaration or expression statement | Keyword statements are not allowed here. |
| &lt;span&gt;`for` condition&lt;/span&gt; | expression | Must evaluate to bool. |
| &lt;span&gt;`for` step&lt;/span&gt; | expression statement | Keyword statements are not allowed here. |
| &lt;span&gt;`foreach` identifier&lt;/span&gt; | new local variable name | Scoped to the loop body. |
| &lt;span&gt;`foreach` enumerable&lt;/span&gt; | expression | Must implement IEnumerable&lt;T&gt;. |
| `..` / `..&` | lower and upper bounds | Both bounds must be int. |

  Range expressions are first-class expressions that produce an
  `int[]`. They can be assigned to a variable, passed to a
  function, or used directly inside `foreach`.

## Returns

  Loop statements do not produce a value. A range expression evaluates to an
  array of integers (`int[]`). `break`
  and `continue` are control-flow statements and also
  produce no value.

## Exceptions / Errors

  - **Non-bool condition** —  `while`, `until`, and C-style  `for` conditions must be boolean expressions.
  - **Invalid range bounds** — Both sides of `..` and `..&` must be `int`.
  - **foreach source not enumerable** —  `foreach` requires a type that implements  `IEnumerable<T>`. Plain object references or unrelated types are rejected at compile time.
  - **break / continue outside a loop** —  Both statements must appear lexically inside a loop body.
  - **Keyword statement in for header** —  `if`, `while`,  `foreach`, and similar keyword statements cannot be used as the initializer or step of a C-style `for`.
  - **Division / modulo by zero** — Any arithmetic in a loop condition or step that divides or modulos by zero throws at runtime.

## Remarks

  **Range semantics.** A range expression allocates a new
  `int[]` containing every integer between the bounds.
  `lower..upper` is half-open: it includes
  `lower` and excludes `upper`.
  `lower..&upper` is inclusive and also includes the
  upper bound. If `upper` is smaller than
  `lower`, the array counts downward. Equal bounds yield an
  empty array for the half-open operator and a single-element array for the
  inclusive operator.

  **foreach implementation.** The compiler lowers
  `foreach` to an enumerator pattern: it calls
  `GetEnumerator()`, then repeatedly calls
  `MoveNext()` and reads `Current`
  until the enumerator reports no more items. This works for arrays, lists,
  dictionaries, and any user-defined type that implements
  `IEnumerable<T>`.

<Info>
Arrays are also `IEnumerable<T>`, so
  `foreach` accepts both ranges and array literals
  directly.
</Info>

  **Legacy for-in syntax.** ShardScript still recognizes
  `for (x in ...)` as an older alias, but the compiler
  restricts it to array sources. New code should prefer
  `foreach` because it accepts any enumerable source and
  matches the standard library pattern.

  **break, continue, and defer.**
  `break` exits the innermost enclosing loop and runs any
  deferred statements owned by scopes that are being left.
  `continue` jumps to the end of the current loop body,
  which is *before* the step expression in a C-style
  `for`. Deferred statements inside the loop body are not
  executed by `continue`; if cleanup is required, use an
  explicit guard or restructure the loop.

  **Infinite loops.** A `while (true)` loop
  with no `break`, `return`, or
  throwing path will run forever. The VM does not currently detect or abort such
  loops.

<Warning title="Compound assignment in loop steps">
Compound assignment operators such as `+=` and
  `-=` are parsed but currently lowered as plain
  assignments by the VM. Until that is fixed, write the step explicitly — for
  example, `i = i + 1` instead of
  `i += 1`.
</Warning>

## Examples

  **while and until.**

// while_until.shard
```csharp
using stdio;

namespace demo;

public static func Main() -> void
{
    counter: int = 0;

    // Run while the condition is true.
    while (counter < 3)
    {
        println(counter);            // 0, 1, 2
        counter = counter + 1;
    }

    // until runs while its condition is false.
    countdown: int = 3;
    until (countdown == 0)
    {
        println(countdown);          // 3, 2, 1
        countdown = countdown - 1;
    }
}
```

  **C-style for with ascending and descending steps.**

// cstyle_for.shard
```csharp
using stdio;

namespace demo;

public static func Main() -> void
{
    // initializer; condition; step
    for (i: int = 0; i < 5; i = i + 1)
    {
        print(i);
        print(" ");
    }
    println("");                     // 0 1 2 3 4

    // Descending step must be written explicitly; there is no automatic stride.
    for (i: int = 10; i > 0; i = i - 2)
    {
        print(i);
        print(" ");
    }
    println("");                     // 10 8 6 4 2
}
```

  **Half-open, inclusive, and reverse ranges.**

// ranges.shard
```csharp
using stdio;

namespace demo;

public static func Main() -> void
{
    // 0..3 is half-open: includes 0, 1, 2.
    half: int[] = 0..3;
    println(half.Length);            // 3

    // 0..&3 is inclusive: includes 0, 1, 2, 3.
    full: int[] = 0..&3;
    println(full.Length);            // 4

    // Reverse range counts down.
    down: int[] = 3..0;
    foreach (n in down)
    {
        println(n);                  // 3, 2, 1
    }

    // Edge cases with equal bounds.
    println((5..5).Length);          // 0
    println((5..&5).Length);         // 1
}
```

  **foreach over arrays, ranges, and collections.**

// foreach.shard
```csharp
using stdio;
using collections;

namespace demo;

public static func Main() -> void
{
    // Array literal.
    nums: int[] = [10, 20, 30];
    foreach (n in nums)
    {
        println(n);
    }

    // Range expression.
    foreach (i in 1..5)
    {
        print(i);
        print(" ");
    }
    println("");                     // 1 2 3 4

    // List<T> implements IEnumerable<T>.
    list: List<int> = new List<int>();
    list.Add(100);
    list.Add(200);
    foreach (value in list)
    {
        println(value);
    }
}
```

  **break and continue.**

// break_continue.shard
```csharp
using stdio;

namespace demo;

public static func Main() -> void
{
    foreach (i in 0..10)
    {
        if (i == 5)
        {
            break;                   // exit the loop entirely
        }

        if (i % 2 == 0)
        {
            continue;                // skip to the next iteration
        }

        println(i);                  // 1, 3
    }
}
```

  **Nested loops and early exit.**

// nested_loops.shard
```csharp
using stdio;

namespace demo;

public static func Main() -> void
{
    // Find the first pair whose product is divisible by 7.
    found: bool = false;

    foreach (a in 2..6)
    {
        foreach (b in 2..6)
        {
            product: int = a * b;
            if (product % 7 == 0)
            {
                println("a=" + a + " b=" + b + " product=" + product);
                found = true;
                break;               // exits only the inner foreach
            }
        }

        if (found)
        {
            break;                   // exits the outer foreach
        }
    }
}
```

  **Common mistakes to avoid.**

  - Writing `i += 1` in a C-style  `for` step currently behaves like a plain assignment. Use `i = i + 1`.
  - Using `break` or `continue` outside any loop is a compile-time error.
  - `foreach` variables are read-only in the sense that rebinding the iteration variable inside the body does not affect the source collection; it only shadows the loop variable.
  - Ranges allocate a temporary array. For very large sequences, consider a C-style `for` loop to avoid the allocation.
