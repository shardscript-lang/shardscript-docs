---
title: Operator Overloading
---

## Summary

  ShardScript lets a class or struct redefine the behavior of built-in operators by declaring
  `operator` members. Overloaded operators are resolved at compile time using
  the static types of their operands, and they follow the same visibility and linking rules as
  methods.

## Syntax

  An operator member is declared inside a class or struct with the
  `operator` keyword, an operator token, a parameter list, an arrow return
  type, and a body:

// operator_overload_syntax.shard
```csharp
public class Vector2
{
    public x: int;
    public y: int;

    public init(x: int, y: int)
    {
        this.x = x;
        this.y = y;
    }

    public static operator +(a: Vector2, b: Vector2) -> Vector2
    {
        return new Vector2(a.x + b.x, a.y + b.y);
    }
}
```

| Operator category | Declaration form | Parameter count |
| --- | --- | ---
| Binary arithmetic and bitwise | `public static operator `*op*`(left: T, right: U) -> R` | 2 |
| Unary | `public static operator `*op*`(operand: T) -> R` | 1 |
| Comparison | `public static operator `*op*`(left: T, right: U) -> bool` | 2 |
| Conversion | `public static operator as(source: T) -> U` | 1 |
| Access (delimiter) | `public operator .(name: string) -> R` | 1 |

  **Overloadable operators.** The compiler accepts the following operator tokens in an
  operator declaration:

| Category | Operators |
| --- | ---
| Arithmetic | +, -, *, /, %, ^ |
| Compound assignment | +=, -=, *=, /=, %=, ^= |
| Bitwise / shift | \|, &, \|=, &=, &gt;&gt;, &lt;&lt; |
| Comparison | ==, !=, &gt;, &gt;=, &lt;, &lt;= |
| Unary | ++, --, ! |
| Conversion | as |
| Access | . |

## Parameters / Arguments

| Parameter | Type | Description |
| --- | --- | ---
| *left* / *operand* / *source* | Any declared type | The first operand. For binary operators this is the left-hand side. For conversion operators it is the value being converted. |
| *right* | Any declared type | The right-hand side of a binary operator. |
| *name* (access operator) | string | The identifier that appears after the dot in a member-access expression. |

## Returns

| Operator | Return type convention | Description |
| --- | --- | ---
| Arithmetic / bitwise | User-defined | Typically the same type as the operands, but any type is allowed. |
| Unary | User-defined | The result of applying the operator to the single operand. |
| Comparison | bool | Comparison operators conventionally return bool, matching built-in comparisons. |
| as | The target type | Returns a value of the type named in the cast expression. |
| . | User-defined | The value produced by the access expression. |

## Exceptions / Errors

  - **Must be declared inside a type** — Operator overloads can only appear as members of a class or struct. Namespace-level operator declarations are not allowed.
  - **Must be public** — The compiler reports an error if an operator overload is not declared `public`.
  - **Most operators must be static** — Arithmetic, bitwise, comparison, unary, and conversion operators must use `static`. The access operator `.` is the only operator that may be an instance member.
  - **Cannot overload operators in static types** — A static class or struct cannot declare operator overloads, except for the access operator.
  - **Wrong parameter count** — Binary operators require exactly two parameters; unary operators and `as` require exactly one. The access operator requires exactly one `string` parameter.
  - **Must have a body** — Abstract or extern operator overloads are not supported.
  - **Non-overloadable token** — Using a token that is not in the overloadable set, such as `operator =` or  `operator &&`, fails during parsing.

## Remarks

  **Resolution rules.** Operator overloads are selected using the compile-time types of
  the operands. The compiler looks for an overload on the left-hand type whose parameter list matches
  the operand types. If no match is found, it reports a semantic error rather than falling back to a
  built-in operator.

  **Static vs instance.** All overloadable operators except `.`
  are static. This matches the design of most binary operators in ShardScript: the operands are passed
  explicitly, and there is no implicit receiver. The access operator is instance because it is invoked
  on a receiver expression such as `obj.field`.

  **Compound assignment.** Overloading `+=` does not automatically
  provide `+`, and vice versa. Each compound-assignment operator is a separate
  overload that is resolved independently.

  **Conversion operator.** `operator as` lets a type participate in
  cast expressions. The return type of the operator is the type the compiler will treat the expression
  as. Both narrowing and widening conversions can be expressed, but the operator is responsible for
  producing a valid value of the target type.

  **Access operator.** `operator .` intercepts member access where
  the member name is not a real declared field, property, or method. The identifier is passed as a
  string, allowing dynamic dispatch based on the name. A type that declares this operator cannot also
  declare public fields.

<Info>
Keep overloaded operators intuitive. Overloading `+` to mean something other
  than addition-like combination, or overloading comparison operators inconsistently, makes code harder
  to reason about.
</Info>

<Warning title="No short-circuiting logical operators">
The logical operators `&&` and `||` are not
  overloadable. The overloadable `&` and `|` are
  bitwise/combined operators and do not short-circuit.
</Warning>

## Examples

  **Binary arithmetic overload.**

// operator_arithmetic.shard
```csharp
using stdio;

namespace demo;

public class Vector2
{
    public x: int;
    public y: int;

    public init(x: int, y: int)
    {
        this.x = x;
        this.y = y;
    }

    public static operator +(a: Vector2, b: Vector2) -> Vector2
    {
        return new Vector2(a.x + b.x, a.y + b.y);
    }

    public static operator -(a: Vector2, b: Vector2) -> Vector2
    {
        return new Vector2(a.x - b.x, a.y - b.y);
    }
}

public static func Main() -> void
{
    v1: Vector2 = new Vector2(1, 2);
    v2: Vector2 = new Vector2(3, 4);

    sum: Vector2 = v1 + v2;
    println(sum.x);   // 4
    println(sum.y);   // 6
}
```

  **Comparison overload.**

// operator_comparison.shard
```csharp
using stdio;

namespace demo;

public class Box
{
    public value: int;

    public init(value: int)
    {
        this.value = value;
    }

    public static operator ==(a: Box, b: Box) -> bool
    {
        return a.value == b.value;
    }

    public static operator !=(a: Box, b: Box) -> bool
    {
        return a.value != b.value;
    }
}

public static func Main() -> void
{
    a: Box = new Box(5);
    b: Box = new Box(5);

    if (a == b)
    {
        println("equal");
    }
}
```

  **Unary overload.**

// operator_unary.shard
```csharp
using stdio;

namespace demo;

public class Vector2
{
    public x: int;
    public y: int;

    public init(x: int, y: int)
    {
        this.x = x;
        this.y = y;
    }

    public static operator !(v: Vector2) -> bool
    {
        return v.x == 0 && v.y == 0;
    }
}

public static func Main() -> void
{
    zero: Vector2 = new Vector2(0, 0);
    nonZero: Vector2 = new Vector2(1, 0);

    if (!zero)
    {
        println("zero vector");
    }

    if (!nonZero)
    {
        println("this will not print");
    }
}
```

  **Conversion with `as`.**

// operator_as.shard
```csharp
using stdio;

namespace demo;

public class Widget
{
    public name: string;

    public init(name: string)
    {
        this.name = name;
    }
}

public class Box
{
    public label: string;

    public init(label: string)
    {
        this.label = label;
    }

    public static operator as(w: Widget) -> Box
    {
        return new Box(w.name);
    }
}

public static func Main() -> void
{
    w: Widget = new Widget("main-widget");
    b: Box = w as Box;

    println(b.label);   // main-widget
}
```

  **Access operator for dynamic members.**

// operator_access.shard
```csharp
using stdio;

namespace demo;

public class Dynamic
{
    public value: int;

    public init(value: int)
    {
        this.value = value;
    }

    public operator .(name: string) -> string
    {
        return name + ":" + this.value;
    }
}

public static func Main() -> void
{
    d: Dynamic = new Dynamic(42);
    println(d.foo);   // foo:42
    println(d.bar);   // bar:42
}
```

  **Common mistake: omitting `static` on a binary operator.**

// operator_static.shard
```csharp
using stdio;

namespace demo;

public class Box
{
    public value: int;

    public init(value: int)
    {
        this.value = value;
    }

    // WRONG: binary operators must be static.
    // public operator +(a: Box, b: Box) -> Box { ... }

    // CORRECT:
    public static operator +(a: Box, b: Box) -> Box
    {
        return new Box(a.value + b.value);
    }
}

public static func Main() -> void
{
    a: Box = new Box(1);
    b: Box = new Box(2);
    c: Box = a + b;

    println(c.value);   // 3
}
```
