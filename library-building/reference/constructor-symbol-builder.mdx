---
title: ConstructorSymbol Builder
---

## Summary

  The `SymbolBuilder<ConstructorSymbol>` API registers constructors on a
  `ClassSymbol` or `StructSymbol`. Constructors are created
  through `AddInit()`, configured with parameters and a native callback, and invoked by
  the runtime when ShardScript code uses the `new` expression. The callback receives the
  freshly allocated instance as `context.Args[0]`, initializes its state, and must return
  that same instance.

## Syntax

  Constructors are registered from inside an `AddClass` or
  `AddStruct` registration block. `AddInit()` returns a
  `SymbolBuilder<ConstructorSymbol>` that is chained with parameter and callback
  configuration.

```cpp
SymbolBuilder<ConstructorSymbol> AddInit(SymbolAccesibility access = SymbolAccesibility::Public);
```

  The constructor builder supports the following fluent methods:

```cpp
SymbolBuilder<ConstructorSymbol>& AddParameter(
    const std::wstring& name,
    TypeSymbol* type);

SymbolBuilder<ConstructorSymbol>& SetCallback(
    MethodSymbolDelegate callback);

SymbolBuilder<TypeParameterSymbol> AddTypeParameter(
    const std::wstring& name);
```

  The native callback has the same signature as a method callback:

```cpp
shard::ObjectInstance* Callback(const shard::CallState& context);
```

## Parameters / Arguments

| Method | Parameters | Returns | Description |
| --- | --- | --- | ---
| `AddInit` | `access = SymbolAccesibility::Public` | `SymbolBuilder<ConstructorSymbol>` | Optional accessibility. Defaults to public. Controls which ShardScript code can invoke the constructor. |
| `AddParameter` | `name`, `type` | `SymbolBuilder<ConstructorSymbol>&` | The parameter name as it appears in ShardScript source and its `TypeSymbol*`. |
| `SetCallback` | `callback` | `SymbolBuilder<ConstructorSymbol>&` | A `MethodSymbolDelegate` function pointer or lambda that the runtime invokes to initialize the instance. |
| `AddTypeParameter` | `name` | `SymbolBuilder<TypeParameterSymbol>` | The name of a generic type parameter for a generic constructor. |

## Returns

  `AddInit` returns a `SymbolBuilder<ConstructorSymbol>`.
  `AddParameter` and `SetCallback` return a reference to the same
  constructor builder so calls can be chained. `AddTypeParameter` returns a
  `SymbolBuilder<TypeParameterSymbol>` for the newly declared generic parameter.

  The native callback must return an `ObjectInstance*` that points to the initialized
  instance. The runtime expects this to be the same pointer that was passed as
  `context.Args[0]`.

## Exceptions / Errors

  - **Callback not registered** — Forgetting to call `.SetCallback(...)` leaves the constructor registered but without a native target. The `new` expression resolves but no initialization code runs.
  - **Wrong instance returned** — Returning a different `ObjectInstance*` than `context.Args[0]` breaks object identity and can confuse the garbage collector or produce an uninitialized object at the call site.
  - **Argument index misalignment** — `context.Args[0]` is the newly allocated instance. The first constructor parameter is at `context.Args[1]`. Reading from index `0` as a parameter value reads the instance itself.
  - **Ambiguous overloads** — Multiple `AddInit` overloads with identical parameter counts and types make constructor resolution ambiguous. Overloads must be distinguishable by parameter count or parameter types.
  - **Inaccessible constructor** — A constructor registered with `ACS_PRIVATE` cannot be invoked by ShardScript code outside its visibility boundary.
  - **Field slot used before registration** — Reading or writing a field in the constructor callback requires the field to have been registered first so that its `SlotIndex` is valid.

## Remarks

<Info title="Native library shape">
A ShardScript native library is any shared library (`.dll` on Windows, `.so` on Linux, `.dylib` on macOS) that exports the two C-linkage symbols `ShardLib_GetMetadata` and `ShardLib_EntryPoint`. It can be built from one or many C++ source files, live inside `ShardScript.Framework` or in a completely separate project, and links against the ShardScript runtime shared library using headers from `ShardScript/include`. For the full registration contract, see `native-library-overview.mdx`.
</Info>

  **Constructor callbacks are instance initializers.** Unlike ordinary methods, a constructor is
  not registered with an explicit `SymbolLinking` argument because
  `AddInit` always describes an instance initializer. The runtime allocates storage for
  the object before the callback runs and passes that instance as `context.Args[0]`. The
  callback's only responsibility is to fill in fields, validate arguments, and return the same pointer.

  **Multiple overloads are supported.** You can register several
  `AddInit` chains on the same type. ShardScript resolves a `new`
  call by matching the supplied argument count and types against the registered parameter lists.

  **Structs follow the same callback contract as classes.** Even though structs are value types,
  the runtime still passes a freshly allocated instance to the constructor callback and expects the callback to
  return it. The VM copies the value as needed after initialization.

  **Generic constructors.** When `AddTypeParameter` is used, the concrete
  type substitutions are available at runtime through `context.Frame->TypeArguments` in
  the order in which the parameters were declared.

  **Field handles must be captured outside the entry point.** Store the
  `FieldSymbol*` returned by `AddField` in a static variable so it
  can be used inside the constructor callback. The `SlotIndex` member is the stable
  runtime offset used by `ObjectInstance::GetField` and
  `ObjectInstance::SetField`.

<Info>
Always return `self` from a constructor callback. Returning
  `nullptr` or a different object is undefined behavior for object construction.
</Info>

<Warning title="AddInit is not a static type initializer">
`AddInit` registers an instance constructor. It is invoked per `new`
  expression. Static type initialization is handled separately by the runtime and is not configured through
  `ConstructorSymbol`.
</Warning>

## Examples

  **Basic class constructor.** A single-parameter constructor stores its argument in a private
  instance field.

// game.shard.cpp
```cpp
static FieldSymbol* g_playerNameField = nullptr;

SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> game(context, L"game");

    game.AddClass(L"Player", ACS_PUBLIC, LINK_INSTANCE, [](SymbolBuilder<ClassSymbol> player)
    {
        g_playerNameField = player.AddField(
            L"_name",
            TYPE_STRING,
            LINK_INSTANCE,
            ACS_PRIVATE);

        player.AddInit()
            .AddParameter(L"name", TYPE_STRING)
            .SetCallback([](const CallState& context)
            {
                ObjectInstance* self = context.Args[0];
                ObjectInstance* name = context.Args[1];
                self->SetField(g_playerNameField->SlotIndex, name);
                return self;
            });
    });
}
```

  ShardScript usage:

```csharp
using stdio;
using game;

namespace demo;

public static func Main() -> void
{
    hero: Player = new Player("Aria");
    println(hero);
}
```

  **Multiple constructor overloads.** Two overloads differ by parameter count so ShardScript can
  construct the object with or without an explicit identifier.

// devices.shard.cpp
```cpp
static FieldSymbol* g_deviceIdField = nullptr;
static FieldSymbol* g_deviceLabelField = nullptr;

SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> devices(context, L"devices");

    devices.AddClass(L"Device", ACS_PUBLIC, LINK_INSTANCE, [](SymbolBuilder<ClassSymbol> device)
    {
        g_deviceIdField = device.AddField(
            L"_id",
            TYPE_INT,
            LINK_INSTANCE,
            ACS_PRIVATE);

        g_deviceLabelField = device.AddField(
            L"_label",
            TYPE_STRING,
            LINK_INSTANCE,
            ACS_PRIVATE);

        device.AddInit()
            .AddParameter(L"id", TYPE_INT)
            .SetCallback([](const CallState& context)
            {
                ObjectInstance* self = context.Args[0];
                ObjectInstance* id = context.Args[1];
                self->SetField(g_deviceIdField->SlotIndex, id);
                self->SetField(g_deviceLabelField->SlotIndex, context.Collector.FromValue(L""));
                return self;
            });

        device.AddInit()
            .AddParameter(L"id", TYPE_INT)
            .AddParameter(L"label", TYPE_STRING)
            .SetCallback([](const CallState& context)
            {
                ObjectInstance* self = context.Args[0];
                ObjectInstance* id = context.Args[1];
                ObjectInstance* label = context.Args[2];
                self->SetField(g_deviceIdField->SlotIndex, id);
                self->SetField(g_deviceLabelField->SlotIndex, label);
                return self;
            });
    });
}
```

  ShardScript usage:

```csharp
using stdio;
using devices;

namespace demo;

public static func Main() -> void
{
    a: Device = new Device(1);
    b: Device = new Device(2, "sensor");
}
```

  **Struct constructor.** Value types use the same `AddInit` pattern and
  return the allocated instance.

// geometry.shard.cpp
```cpp
static FieldSymbol* g_pointXField = nullptr;
static FieldSymbol* g_pointYField = nullptr;

SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> geometry(context, L"geometry");

    SymbolBuilder<StructSymbol> point = geometry.AddStruct(L"Point", ACS_PUBLIC, LINK_INSTANCE);

        g_pointXField = point.AddField(
            L"X",
            TYPE_INT,
            LINK_INSTANCE,
            ACS_PUBLIC);

        g_pointYField = point.AddField(
            L"Y",
            TYPE_INT,
            LINK_INSTANCE,
            ACS_PUBLIC);

        point.AddInit()
            .AddParameter(L"x", TYPE_INT)
            .AddParameter(L"y", TYPE_INT)
            .SetCallback([](const CallState& context)
            {
                ObjectInstance* self = context.Args[0];
                ObjectInstance* x = context.Args[1];
                ObjectInstance* y = context.Args[2];
                self->SetField(g_pointXField->SlotIndex, x);
                self->SetField(g_pointYField->SlotIndex, y);
                return self;
            });
    }
}
```

  ShardScript usage:

```csharp
using stdio;
using geometry;

namespace demo;

public static func Main() -> void
{
    origin: Point = new Point(0, 0);
    println(origin.X);
    println(origin.Y);
}
```
