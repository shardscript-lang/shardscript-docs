title: Native Callback Helpers
---

## Summary

  `GetArgs<T...>` is a variadic template helper declared in
  `<shard/runtime/NativeHelpers.hpp>` that unpacks the borrowed
  arguments in a `CallState` into a typed
  `std::tuple<T...>`. It checks the argument count, guards against
  null pointers, and dispatches each element to the correct `ObjectInstance`
  reader for the requested C++ type.

## Syntax

// NativeHelpers.hpp
```cpp
#include <shard/runtime/NativeHelpers.hpp>

std::tuple<TArgs...> shard::GetArgs<TArgs...>(const shard::CallState& context);
```

## Parameters / Arguments

  The `context` argument is the callback state passed to every native method.
  The template parameters `TArgs...` must be a supported type combination and
  must appear in the same order as the registered parameters.

| Template parameter | C++ type | ShardScript type | How it is read |
| --- | --- | --- | ---
| `bool` | `bool` | `bool` | `AsBoolean()` |
| `std::int64_t` | `std::int64_t` | `int` | `AsInteger()` |
| `double` | `double` | `double` | `AsDouble()` |
| `wchar_t` | `wchar_t` | `char` | `AsCharacter()` |
| `std::uint8_t` | `std::uint8_t` | `byte` | `AsByte()` |
| `const wchar_t*` | `const wchar_t*` | `string` | `AsString()` |
| `std::wstring` | `std::wstring` | `string` | ['Copies ', `AsString()`, ' into a new ', `std::wstring`] |
| `ObjectInstance*` | `shard::ObjectInstance*` | any reference type | Returns the argument pointer as-is |
| `T*` | any native pointer type | `nint` | ['Casts ', `AsNint()`, ' to ', `T*`] |

## Returns

  Returns a `std::tuple<TArgs...>` whose elements are in the same order
  as `context.Args` and the template arguments. Extract the values with
  `std::tie` or `std::get`. The returned values are
  borrowed from the caller; they are not owned by the helper.

## Exceptions / Errors

  - Throws `std::runtime_error` when the number of template arguments does not match `context.Args.size()`.
  - Throws `std::runtime_error` when an argument index is out of range.
  - Throws `std::runtime_error` when an argument pointer is  `nullptr`.
  - Throws `std::runtime_error` when a value-type argument resolves to  `GarbageCollector::NullInstance`. Only  `ObjectInstance*` and native pointer types allow null.

## Remarks

  `GetArgs` is a convenience wrapper around the manual readers on
  `ObjectInstance`. It does not change ownership: arguments remain borrowed from
  the caller, and the returned tuple contains raw pointers or primitive copies.

  Use `GetArgs` for simple static callbacks whose parameters are all primitive
  values in registration order. For instance methods, do not use it for the real parameters, because
  `context.Args[0]` is `this`. The template types would
  shift by one position and read the wrong objects.

  Do not use `GetArgs` for reference-typed arguments that may be null and need
  special handling. A `const wchar_t*` or `std::wstring`
  argument throws if the script passes `null`. Read such arguments manually so
  you can return a safe default or a meaningful error.

  The `std::wstring` overload copies the string payload, so the copy is safe to
  keep after the callback returns. The `const wchar_t*` overload returns a view
  into GC-managed memory; do not store that pointer past the next allocation or collection point.

<Info title="Native library shape">
A ShardScript native library is any shared library (`.dll` on Windows, `.so` on Linux, `.dylib` on macOS) that exports the two C-linkage symbols `ShardLib_GetMetadata` and `ShardLib_EntryPoint`. It can be built from one or many C++ source files, live inside `ShardScript.Framework` or in a completely separate project, and links against the ShardScript runtime shared library using headers from `ShardScript/include`. For the full registration contract, see `native-library-overview.mdx`.
</Info>

<Info>
Native pointer extraction casts `AsNint()` to the requested type. The
  ShardScript side must actually pass a `nint` value; the helper does not
  validate that the pointer belongs to the expected C++ type.
</Info>

## Examples

  Read two `double` arguments for a static method.

// mathdemo.cpp
```cpp
#include <ShardScript.hpp>
#include <shard/runtime/NativeHelpers.hpp>

#include <cmath>

using namespace shard;

static ObjectInstance* hypotenuse(const CallState& context)
{
    double a = 0.0;
    double b = 0.0;

    std::tie(a, b) = GetArgs<double, double>(context);

    double result = std::sqrt((a * a) + (b * b));
    return context.Collector.FromValue(result);
}

SHARDLIB_GETMETADATA
{
    lib.Name        = L"shard.mathdemo";
    lib.Description = L"GetArgs demonstration";
    lib.Version     = L"1.0.0";
}

SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> ns(context, L"mathdemo");

    ns.AddClass(L"Math", ACS_PUBLIC, LINK_STATIC, [](SymbolBuilder<ClassSymbol> type)
    {
        type.AddMethod(L"Hypotenuse", TYPE_DOUBLE, LINK_STATIC, ACS_PUBLIC)
            .AddParameter(L"a", TYPE_DOUBLE)
            .AddParameter(L"b", TYPE_DOUBLE)
            .SetCallback(&hypotenuse);
    });
}
```

  Read mixed primitive types in the order they were registered.

// mathdemo.cpp
```cpp
static ObjectInstance* power(const CallState& context)
{
    double base = 0.0;
    std::int64_t exponent = 0;

    std::tie(base, exponent) = GetArgs<double, std::int64_t>(context);

    double result = std::pow(base, static_cast<double>(exponent));
    return context.Collector.FromValue(result);
}
```

  The following ShardScript program loads the library and calls the static methods.

// app.shard
```csharp
using stdio;
using mathdemo;

namespace app;

public class Program
{
    public static func Main() -> void
    {
        double h = Math.Hypotenuse(3.0, 4.0);
        println("hypotenuse: " + h);

        double p = Math.Power(2.0, 8);
        println("power: " + p);
    }
}
```
