---
title: PropertySymbol Builder
---

## Summary

  The `PropertySymbol` builder registers a ShardScript property on a class, struct, or
  interface from inside a native C++ library. A property exposes one or two accessor methods — a getter, a
  setter, or both — and may optionally be backed by a compiler-managed field. Registration is fluent: call
  `AddProperty` on a type builder, then chain `AddGetter`,
  `AddSetter`, and `SetCallback` to bind native callbacks.

## Syntax

  Properties are created from a `SymbolBuilder<ClassSymbol>`,
  `SymbolBuilder<StructSymbol>`, or
  `SymbolBuilder<InterfaceSymbol>`.

```cpp
// Register a read-only static property.
type.AddProperty(L"Pi", TYPE_DOUBLE, LINK_STATIC, ACS_PUBLIC)
    .AddGetter()
    .SetCallback(&get_pi);

// Register a read-write instance property.
type.AddProperty(L"Length", TYPE_INT, LINK_INSTANCE, ACS_PUBLIC)
    .AddGetter().SetCallback(&get_length)
    .AddSetter().SetCallback(&set_length);

// Register a property with an auto-backing field.
SymbolBuilder<PropertySymbol> nameProp = type.AddProperty(L"Name", TYPE_STRING, LINK_INSTANCE, ACS_PUBLIC);
FieldSymbol* backing = nameProp.AddBackingField().Get();

nameProp.AddGetter().SetCallback(&get_name);
nameProp.AddSetter().SetCallback(&set_name);
```

## Parameters / Arguments

| Parameter | Type | Description |
| --- | --- | ---
| `name` | `const wchar_t*` | Required. The ShardScript identifier of the property, for example L"Length". |
| `type` | `TypeSymbol*` | Required. The property type. Use built-in constants such as TYPE_INT, TYPE_DOUBLE, TYPE_STRING, TYPE_BOOL, or a TypeSymbol*. |
| `linking` | `SymbolLinking` | Required. LINK_STATIC for a type-level property; LINK_INSTANCE for an instance property. |
| `accessibility` | `SymbolAccesibility` | Required. ACS_PUBLIC or ACS_PRIVATE. Controls which ShardScript code can access the property. |

  **Accessor builder methods**

| Method | Description |
| --- | ---
| `AddGetter()` | Adds a getter accessor to the property. The callback must return a value of the property type. |
| `AddSetter()` | Adds a setter accessor to the property. The callback receives the new value as its last argument and returns nullptr. |
| `AddBackingField()` | Creates a compiler-managed field that backs the property. Returns a SymbolBuilder&lt;FieldSymbol&gt;; call .Get() to obtain the FieldSymbol* for runtime read/write. |
| `SetCallback(callback)` | Binds a native callback to the most recently added accessor (getter or setter). |
| `SetMayThrow(value)` | Marks the current accessor as potentially throwing an exception. Defaults to `true`. |
| `SetThrowsType(type)` | Marks the current accessor as throwing a specific managed exception type; sets `MayThrow` and adds the type to `ThrownTypes`. |
| `SetMutatesInstance(value)` | Marks the current accessor as writing instance state of `this`. Defaults to `true`. |
| `SetMutatesStatic(value)` | Marks the current accessor as writing static state of the enclosing type. Defaults to `true`. |
| `SetMutatesArguments(value)` | Marks the current accessor as writing through by-ref/out parameters (reserved). Defaults to `true`. |
| `SetHasUnknownSideEffects(value)` | Marks the current accessor as having side effects the compiler cannot analyze. Defaults to `true`. |

## Returns

  `AddProperty` returns a `PropertySymbol&` (wrapped by the
  fluent `SymbolBuilder<PropertySymbol>`) so you can chain accessor registration.
  `AddBackingField` returns `SymbolBuilder<FieldSymbol>`; call `.Get()` to obtain the `FieldSymbol*`, which exposes
  `SlotIndex` for runtime field access. `SetCallback` returns a
  reference to the accessor builder so additional parameters may be chained, although property accessors
  typically take no explicit parameters beyond the implicit `this` and setter value.

## Exceptions / Errors

  - **Accessor callback never invoked** — Forgetting  `.SetCallback(...)` after `AddGetter` or  `AddSetter` registers the accessor without a native target. Reading or writing the property resolves but no code runs.
  - **Static property accessed through an instance** — A property registered with `LINK_STATIC` must be read or written through the type name, for example `Type.Property`. Instance access produces a semantic error.
  - **Instance property accessed through the type** — A property registered with `LINK_INSTANCE` must be accessed through an object reference, for example `obj.Property`. Type-level access produces a semantic error.
  - **Setter argument misalignment** — For an instance setter, `context.Args[0]` is `this` and  `context.Args[1]` is the new value. For a static setter,  `context.Args[0]` is the new value. Reading at the wrong index causes incorrect values or a crash.
  - **Return type mismatch** — A getter callback must return an `ObjectInstance*` whose runtime type matches the registered property type. Returning a differently typed value may corrupt the managed heap or cause a cast failure.
  - **Backing field accessed before registration** — The  `FieldSymbol*` returned by `AddBackingField` is valid only after `SHARDLIB_ENTRYPOINT` runs. Do not read `SlotIndex` during static initialization.

## Remarks

<Info title="Native library shape">
A ShardScript native library is any shared library (`.dll` on Windows, `.so` on Linux, `.dylib` on macOS) that exports the two C-linkage symbols `ShardLib_GetMetadata` and `ShardLib_EntryPoint`. It can be built from one or many C++ source files, live inside `ShardScript.Framework` or in a completely separate project, and links against the ShardScript runtime shared library using headers from `ShardScript/include`. For the full registration contract, see `native-library-overview.mdx`.
</Info>

  **Getter callback contract.** A getter callback receives the same
  `shard::CallState` as a method. For an instance property,
  `context.Args[0]` is `this`. For a static property, there is no
  implicit `this` and `context.Args` is empty. The callback must
  return a GC-owned `ObjectInstance*` produced by
  `context.Collector.FromValue(...)` or a similar allocator.

  **Setter callback contract.** A setter callback receives the new value as its last argument and
  must return `nullptr` (the property expression evaluates to void). For an instance
  property, `context.Args[0]` is `this` and
  `context.Args[1]` is the value. For a static property,
  `context.Args[0]` is the value.

  **Auto-backing fields.** Call `AddBackingField()` to create a
  compiler-managed field for the property. Store the returned `FieldSymbol*` and use
  `instance->SetField(backingField->SlotIndex, value)` and
  `instance->GetField(backingField->SlotIndex)` in the getter and setter callbacks. The
  field&apos;s accessibility controls whether ShardScript code can read it directly; in most cases it should be
  `ACS_PRIVATE` so callers are forced through the property accessors.

  **Static properties for constants.** A read-only static property is the preferred way to expose
  library constants from a native library. It is safer than a public static field because there is no setter, and
  it matches the pattern used by libraries such as `shard.math`.

  **Properties on interfaces.** Interfaces can declare properties so that implementing types must
  provide matching accessors. Interface property registration uses the same `AddProperty`
  call, but without `SetCallback`; the accessor bodies are supplied by the implementing
  class or struct.

  **Accessor effect summaries.** Property getters and setters are represented as
  `AccessorSymbol` symbols and participate in the same side-effect analysis as methods.
  Because native callback bodies are invisible to the ShardScript flow analyzer, you can declare an
  accessor's effects explicitly with `SetMayThrow`, `SetMutatesInstance`,
  `SetMutatesStatic`, `SetMutatesArguments`, and
  `SetHasUnknownSideEffects`. These bits are merged into callers' effect summaries and
  influence compiler warnings. All five boolean setters default to `true` and return the same
  accessor builder for chaining. Use `SetThrowsType(type)` when an accessor callback
  raises a specific managed exception type; it also sets `MayThrow` so the warning can
  name the type.

<Info>
Prefer `AddBackingField` when the property simply stores and returns a value. Use
  explicit getter/setter callbacks when the read or write involves computation, validation, or a side effect such
  as updating a native handle.
</Info>

## Examples

  **Read-only static property.** This is the most common way to expose a constant from a native
  library. There is no setter and no instance state.

// math.shard.cpp
```cpp
static ObjectInstance* get_pi(const CallState& context)
{
    // No arguments for a static getter; simply return the constant value.
    return context.Collector.FromValue(3.14159);
}

SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> math(context, L"math");

    math.AddClass(L"Math", ACS_PUBLIC, LINK_STATIC, [](SymbolBuilder<ClassSymbol> mathClass)
    {
        mathClass.AddProperty(L"Pi", TYPE_DOUBLE, LINK_STATIC, ACS_PUBLIC)
            .AddGetter()
            .SetCallback(&get_pi);
    });
}
```

  ShardScript usage:

```csharp
using stdio;
using math;

namespace demo;

public static func Main() -> void
{
    radius: double = 2.0;
    circumference: double = 2.0 * Math.Pi * radius;
    println(circumference);   // 12.56636
}
```

  **Read-write instance property with explicit callbacks.** The getter computes a value from a
  private native handle; the setter validates the input before storing it.

// buffers.shard.cpp
```cpp
static FieldSymbol* g_bufferHandle = nullptr;

static ObjectInstance* get_capacity(const CallState& context)
{
    ObjectInstance* self = context.Args[0];
    ObjectInstance* handleObj = self->GetField(g_bufferHandle->SlotIndex);
    std::int64_t handle = handleObj->AsInteger();

    // Capacity is derived from the opaque native handle value in this example.
    std::int64_t capacity = handle * 1024;

    return context.Collector.FromValue(capacity);
}

static ObjectInstance* set_capacity(const CallState& context)
{
    ObjectInstance* self = context.Args[0];
    std::int64_t newCapacity = context.Args[1]->AsInteger();

    if (newCapacity < 0)
    {
        // Negative capacity is not meaningful for this type.
        newCapacity = 0;
    }

    // Convert the managed capacity back into the opaque handle representation.
    std::int64_t handle = newCapacity / 1024;
    self->SetField(g_bufferHandle->SlotIndex, context.Collector.FromValue(handle));

    return nullptr;
}

SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> buffers(context, L"buffers");

    buffers.AddClass(L"Buffer", ACS_PUBLIC, LINK_INSTANCE, [](SymbolBuilder<ClassSymbol> buffer)
    {
        g_bufferHandle = buffer.AddField(L"_handle", TYPE_INT, LINK_INSTANCE, ACS_PRIVATE);

        buffer.AddProperty(L"Capacity", TYPE_INT, LINK_INSTANCE, ACS_PUBLIC)
            .AddGetter().SetCallback(&get_capacity)
            .AddSetter().SetCallback(&set_capacity);
    });
}
```

  ShardScript usage:

```csharp
using stdio;
using buffers;

namespace demo;

public static func Main() -> void
{
    b: Buffer = new Buffer();
    b.Capacity = 4096;
    println(b.Capacity);   // 4096
}
```

  **Property with an auto-backing field.** The compiler allocates the storage. The native callbacks
  read and write the backing field slot directly.

// config.shard.cpp
```cpp
static FieldSymbol* g_nameField = nullptr;

static ObjectInstance* get_name(const CallState& context)
{
    ObjectInstance* self = context.Args[0];
    ObjectInstance* name = self->GetField(g_nameField->SlotIndex);

    if (name == nullptr || name == GarbageCollector::NullInstance)
    {
        // Return an empty string when no value has been set.
        return context.Collector.FromValue(std::wstring());
    }

    return name;
}

static ObjectInstance* set_name(const CallState& context)
{
    ObjectInstance* self = context.Args[0];
    ObjectInstance* newName = context.Args[1];

    if (newName == nullptr || newName == GarbageCollector::NullInstance)
    {
        // Treat null assignment as an empty string for this property.
        self->SetField(g_nameField->SlotIndex, context.Collector.FromValue(std::wstring()));
    }
    else
    {
        self->SetField(g_nameField->SlotIndex, newName);
    }

    return nullptr;
}

SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> config(context, L"config");

    config.AddClass(L"Settings", ACS_PUBLIC, LINK_INSTANCE, [](SymbolBuilder<ClassSymbol> settings)
    {
        SymbolBuilder<PropertySymbol> nameProp = settings.AddProperty(L"Name", TYPE_STRING, LINK_INSTANCE, ACS_PUBLIC);

        g_nameField = nameProp.AddBackingField();
        nameProp.AddGetter().SetCallback(&get_name);
        nameProp.AddSetter().SetCallback(&set_name);
    });
}
```

  **Read-write static property.** Static properties can also have both a getter and a setter. They
  are useful for module-level settings that do not belong to any instance.

// logging.shard.cpp
```cpp
static std::int64_t g_logLevel = 0;

static ObjectInstance* get_loglevel(const CallState& context)
{
    return context.Collector.FromValue(g_logLevel);
}

static ObjectInstance* set_loglevel(const CallState& context)
{
    std::int64_t level = context.Args[0]->AsInteger();

    if (level < 0)
    {
        level = 0;
    }
    else if (level > 3)
    {
        level = 3;
    }

    g_logLevel = level;
    return nullptr;
}

SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> logging(context, L"logging");

    logging.AddClass(L"Log", ACS_PUBLIC, LINK_STATIC, [](SymbolBuilder<ClassSymbol> logClass)
    {
        logClass.AddProperty(L"Level", TYPE_INT, LINK_STATIC, ACS_PUBLIC)
            .AddGetter().SetCallback(&get_loglevel)
            .AddSetter().SetCallback(&set_loglevel);
    });
}
```

  ShardScript usage:

```csharp
using stdio;
using logging;

namespace demo;

public static func Main() -> void
{
    Log.Level = 2;
    println(Log.Level);   // 2

    Log.Level = 10;
    println(Log.Level);   // 3, clamped by the setter
}
```

  **Common mistake: reading the wrong argument in an instance setter.** Remember that instance
  accessors always receive `this` as `context.Args[0]`.

```cpp
buffer.AddProperty(L"Capacity", TYPE_INT, LINK_INSTANCE, ACS_PUBLIC)
    .AddSetter()
    .SetCallback([](const CallState& context)
    {
        // CORRECT: this is Args[0], the new value is Args[1].
        ObjectInstance* self = context.Args[0];
        std::int64_t value = context.Args[1]->AsInteger();

        // WRONG: this would read this as the new value.
        // std::int64_t value = context.Args[0]->AsInteger();

        self->SetField(g_bufferHandle->SlotIndex, context.Collector.FromValue(value));
        return nullptr;
    });
```
