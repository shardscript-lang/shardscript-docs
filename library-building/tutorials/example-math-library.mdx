## Summary

  The `shard.math` native library registers a single static class,
  `math.Math`, that exposes read-only mathematical constants as properties and
  wraps standard C math functions as static methods. It is the smallest framework library and the
  recommended starting point for learning how to author a stateless native shard.
  `shard.math` is a shared library built from `system/math.shard.cpp`.
  It exports `ShardLib_GetMetadata` and `ShardLib_EntryPoint`,
  registers the `math` namespace, and adds a static `Math` class
  containing the constants `PI` and `E` plus methods such as
  `Sin`, `Pow`, and `Sqrt`. Every member
  uses static linking, so ShardScript code calls them through the type name rather than through an instance.

## Syntax

  A native math library is a normal shared library that defines the two required entry points and registers
  symbols inside `SHARDLIB_ENTRYPOINT`. The static class pattern looks like this:

```cpp
SHARDLIB_GETMETADATA
{
    lib.Name        = L"shard.math";
    lib.Description = L"High-performance native math library wrappers";
    lib.Version     = L"1.0.0";
}

SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> mathNamespace(context, L"math");

    mathNamespace.AddClass(L"Math", ACS_PUBLIC, LINK_STATIC, [](SymbolBuilder<ClassSymbol> math)
    {
        math.AddProperty(L"PI", TYPE_DOUBLE, LINK_STATIC, ACS_PUBLIC)
            .AddGetter().SetCallback([](const CallState& context)
            {
                return context.Collector.FromValue(3.14159265358979323846);
            });

        math.AddMethod(L"Sin", TYPE_DOUBLE, LINK_STATIC, ACS_PUBLIC)
            .AddParameter(L"value", TYPE_DOUBLE)
            .SetCallback([](const CallState& context)
            {
                auto [value] = GetArgs<double>(context);
                return context.Collector.FromValue(std::sin(value));
            });
    });
}
```

## Parameters / Arguments

| Method | Parameters | Returns | Description |
| --- | --- | --- | ---
| `AddClass` | `L"Math"`, `ACS_PUBLIC`, `LINK_STATIC` | `ClassSymbol*` | Registers the static ShardScript-visible class name. |
| `AddProperty` | `L"PI" / L"E"`, `TYPE_DOUBLE`, `LINK_STATIC`, `ACS_PUBLIC` | `SymbolBuilder<PropertySymbol>&` | Registers a read-only constant property. |
| `AddMethod` | `L"Sin" etc.`, `TYPE_DOUBLE`, `LINK_STATIC`, `ACS_PUBLIC` | `SymbolBuilder<MethodSymbol>&` | Registers a static method called as Math.Name(...). |
| `AddParameter` | `L"value" / L"a" / L"b" etc.`, `TYPE_DOUBLE` | `SymbolBuilder<MethodSymbol>&` | Adds a parameter used for overload resolution. |
| `GetArgs<T...>` | `T...` | `std::tuple<T...>` | Reads context.Args into C++ primitive types in registration order. |

## Exceptions / Errors

  - **Domain error from the C runtime** — Methods such as `Math.Sqrt` call `std::sqrt` directly. Passing a negative value produces a NaN result rather than a ShardScript exception.
  - **Argument count mismatch** — Calling `Math.Pow(2.0)` with one argument fails semantic overload resolution because the method is registered with two `TYPE_DOUBLE` parameters.
  - **Type mismatch** — Passing an `int` to `Math.Sin` is rejected at compile time unless an implicit conversion to `double` exists.
  - **Static member called on an instance** — Because `Math` is registered with `LINK_STATIC`, constructing an instance with `new Math()` is invalid.
  - **Missing callback** — Forgetting `.SetCallback(...)` on a property getter or method registers the symbol but never runs native code when invoked.

## Remarks

<Info title="Native library shape">
A ShardScript native library is any shared library (`.dll` on Windows, `.so` on Linux, `.dylib` on macOS) that exports the two C-linkage symbols `ShardLib_GetMetadata` and `ShardLib_EntryPoint`. It can be built from one or many C++ source files, live inside `ShardScript.Framework` or in a completely separate project, and links against the ShardScript runtime shared library using headers from `ShardScript/include`. For the full registration contract, see `native-library-overview.mdx`.
</Info>

  **Static class registration.** The class itself is registered with
  `LINK_STATIC`. This tells the semantic model that the type has no instance layout and
  that every member is reached through the type name. Static classes are the right shape for stateless utility
  libraries such as math, constants, or pure functions.

  **Read-only constants as properties.** `PI` and `E`
  are registered with `AddProperty` and a getter callback, not as fields. Properties with
  only a getter are read-only from ShardScript and prevent callers from mutating the constant.

  **The GetArgs helper.** The `GetArgs<T...>` convenience helper reads
  `context.Args` from index zero in order and converts each argument to the requested C++
  primitive type. For a static method, index zero is the first real parameter; for an instance method it would
  be `this`.

<Warning title="Structured bindings and implicit typing">
The `auto [value] = GetArgs<T>(context);` syntax uses C++ structured bindings, which require `auto`. This is an intentional exception to the explicit-typing rule used elsewhere in native library code.
</Warning>

  **Returning values.** Every callback boxes its result through
  `context.Collector.FromValue(...)`. The collector owns the returned object, so the
  callback does not free it. Properties and methods that produce `void` return
  `nullptr`.

<Info>
Keep utility libraries stateless. If you find yourself adding instance fields to a math class, consider
  whether the feature belongs in a separate type with `LINK_INSTANCE` instead.
</Info>

## Examples

  **Complete library source.** This is the framework implementation of
  `system/math.shard.cpp`.

// math.shard.cpp
```cpp
#include <ShardScript.hpp>
#include <cmath>

using namespace shard;

SHARDLIB_GETMETADATA
{
    lib.Name = L"shard.math";
    lib.Description = L"High-performance native math library wrappers";
    lib.Version = L"1.0.0";
}

SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> mathNamespace(context, L"math");

    mathNamespace.AddClass(L"Math", ACS_PUBLIC, LINK_STATIC, [](SymbolBuilder<ClassSymbol> math)
    {
        math.AddProperty(L"PI", TYPE_DOUBLE, LINK_STATIC, ACS_PUBLIC)
            .AddGetter().SetCallback([](const CallState& context)
            {
                return context.Collector.FromValue(3.14159265358979323846);
            });

        math.AddProperty(L"E", TYPE_DOUBLE, LINK_STATIC, ACS_PUBLIC)
            .AddGetter().SetCallback([](const CallState& context)
            {
                return context.Collector.FromValue(2.71828182845904523536);
            });

        math.AddMethod(L"Sin", TYPE_DOUBLE, LINK_STATIC, ACS_PUBLIC)
            .AddParameter(L"value", TYPE_DOUBLE)
```

  **Build it as a standalone shared library.** The file can be compiled outside the framework tree
  with a normal CMake shared-library target.

// CMakeLists.txt
```cmake
cmake_minimum_required(VERSION 3.20)
project(shard.math CXX)

set(CMAKE_CXX_STANDARD 20)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

# Path to the ShardScript checkout or installation prefix.
set(SHARDSCRIPT_ROOT "\${CMAKE_CURRENT_SOURCE_DIR}/../ShardScript"
    CACHE PATH "Root of the ShardScript repository or install prefix")

find_library(SHARDSCRIPT_LIB
    NAMES ShardScript libShardScript
    PATHS "\${SHARDSCRIPT_ROOT}/build/bin" "\${SHARDSCRIPT_ROOT}/lib"
    NO_DEFAULT_PATH
    REQUIRED
)

add_library(math SHARED math.shard.cpp)

set_target_properties(math PROPERTIES
    WINDOWS_EXPORT_ALL_SYMBOLS ON
)

target_include_directories(math PRIVATE "\${SHARDSCRIPT_ROOT}/ShardScript/include")
target_link_libraries(math PRIVATE \${SHARDSCRIPT_LIB})
```

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
```

  **ShardScript usage.** Import the `math` namespace and call
  `Math` members through the type name.

// app.shard
```csharp
using stdio;
using math;

namespace demo;

public static func Main() -> void
{
    radius: double = 5.0;
    area: double = Math.PI * Math.Pow(radius, 2.0);
    println("Area: " + area);

    hypotenuse: double = Math.Sqrt(Math.Pow(3.0, 2.0) + Math.Pow(4.0, 2.0));
    println("Hypotenuse: " + hypotenuse);

    smaller: double = Math.Min(10.0, 3.0);
    println("Min: " + smaller);
}
```

  Run the program and load the shared library by path.

```bash
# Windows
shard app.shard -l build/math.dll

# Linux
shard app.shard -l build/libmath.so

# macOS
shard app.shard -l build/libmath.dylib
```

<Tip title="Expected output">
The program prints the calculated area, hypotenuse, and minimum value. Because the library is stateless, the
  order of calls does not matter and repeated calls produce the same result for the same inputs.
</Tip>
