title: Working with Fields
---

## Prerequisites

  - A C++ shared library that exports `ShardLib_GetMetadata` and  `ShardLib_EntryPoint`. The library may contain one source file or many, and it may live inside `ShardScript.Framework` or in a completely separate project.
  - The ShardScript runtime headers available on the include path, typically  `ShardScript/include`.
  - A linked ShardScript runtime shared library so the binary can resolve symbols such as  `ObjectInstance`, `GarbageCollector`, and  `SymbolBuilder`.
  - Familiarity with the callback contract from `library-building/accessibility-and-linking`  or `library-building/shardlib-entrypoint`.

## Goal

  Register fields on ShardScript types from native C++ code, then read and write them inside callbacks. This
  guide covers instance fields, static fields, private native handles, and the backing fields used by properties.
  By the end you will know how to use `FieldSymbol->SlotIndex` as the stable runtime key
  for object storage.

## Step-by-Step Instructions

  **1. Keep a global pointer to every FieldSymbol you register.**

  `AddField` returns a `FieldSymbol*`. Store that pointer in a
  file-scope static variable. The field object carries a `SlotIndex`, which is the stable
  offset the runtime uses when it allocates instances of the containing type. The actual numeric value is assigned
  by the semantic model, so your code must read it from the symbol at runtime rather than hard-coding an index.

```cpp
#include <ShardScript.hpp>

using namespace shard;

// Pointers are filled in inside SHARDLIB_ENTRYPOINT and read by callbacks.
static FieldSymbol* g_sensor_idField     = nullptr;
static FieldSymbol* g_sensor_handleField = nullptr;
static FieldSymbol* g_sensor_nextIdField = nullptr;
```

  **2. Register instance fields, static fields, and private handles.**

  Pass a `SymbolLinking` value and an accessibility value to
  `AddField`. `LINK_INSTANCE` stores the field per object;
  `LINK_STATIC` stores it once per type. Mark implementation-only storage such as native
  handles with `ACS_PRIVATE` so ShardScript callers cannot access them directly.

```cpp
SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> devices(context, L"devices");

    devices.AddClass(L"Sensor", ACS_PUBLIC, LINK_INSTANCE, [](SymbolBuilder<ClassSymbol> sensor)
    {
        // Per-instance state.
        g_sensor_idField = sensor.AddField(L"_id", TYPE_INT, LINK_INSTANCE, ACS_PRIVATE);

        // Per-instance native handle. ACS_PRIVATE keeps it out of ShardScript code.
        g_sensor_handleField = sensor.AddField(L"_handle", TYPE_NINT, LINK_INSTANCE, ACS_PRIVATE);

        // Shared state: one value for the whole type.
        g_sensor_nextIdField = sensor.AddField(L"_nextId", TYPE_INT, LINK_STATIC, ACS_PRIVATE);

        sensor.AddInit()
            .SetCallback([](const CallState& context)
            {
                ObjectInstance* self = context.Args[0];

                // Read and increment the static counter.
                std::int64_t nextId = context.Collector.GetStaticField(g_sensor_nextIdField)->AsInteger();
                context.Collector.SetStaticField(g_sensor_nextIdField, context.Collector.FromValue(nextId + 1));

                // Assign the instance id and a synthetic native handle.
                self->SetField(g_sensor_idField->SlotIndex, context.Collector.FromValue(nextId));
                self->SetField(g_sensor_handleField->SlotIndex, context.Collector.FromNint(nullptr, true));

                return self;
            });

        sensor.AddMethod(L"Read", TYPE_DOUBLE, LINK_INSTANCE, ACS_PUBLIC)
            .SetCallback([](const CallState& context)
            {
                ObjectInstance* self = context.Args[0];
                ObjectInstance* handleObj = self->GetField(g_sensor_handleField->SlotIndex);

                // In a real library the handle would be cast back to a device pointer.
                std::int64_t handle = handleObj->AsInteger();
                double sample = static_cast<double>(handle + self->GetField(g_sensor_idField->SlotIndex)->AsInteger());

                return context.Collector.FromValue(sample);
            });
    });
}
```

<Info title="Why keep the FieldSymbol*">
The semantic model may reorder fields or insert hidden slots for value-type layout.
  `FieldSymbol->SlotIndex` is the only supported way to know where a field lives at
  runtime. Hard-coding slot numbers will break when the type changes.
</Info>

  **3. Read and write instance fields.**

  Inside an instance callback, `context.Args[0]` is `this`. Use
  `ObjectInstance::GetField(std::uint32_t)` and
  `SetField(std::uint32_t, ObjectInstance*)` with the field&apos;s
  `SlotIndex`. Values passed to `SetField` must be GC-owned
  instances produced by `context.Collector`.

```cpp
static ObjectInstance* sensor_reset(const CallState& context)
{
    ObjectInstance* self = context.Args[0];

    // Read the current id; we keep it but reset the synthetic handle.
    std::int64_t id = self->GetField(g_sensor_idField->SlotIndex)->AsInteger();

    // Write a new boxed int back into the instance slot.
    self->SetField(g_sensor_idField->SlotIndex, context.Collector.FromValue(id));
    self->SetField(g_sensor_handleField->SlotIndex, context.Collector.FromNint(nullptr, true));

    return nullptr;
}
```

  **4. Read and write static fields.**

  Static fields are owned by the `GarbageCollector`, not by any instance. Read them with
  `context.Collector.GetStaticField(FieldSymbol*)` and write them with
  `context.Collector.SetStaticField(FieldSymbol*, ObjectInstance*)`. Because static fields
  are shared across the application domain, guard writes carefully and prefer immutable configuration values when
  possible.

```cpp
static ObjectInstance* sensor_resetCounter(const CallState& context)
{
    // Static method: no 'this', Args[0] is the first real parameter.
    std::int64_t value = context.Args[0]->AsInteger();

    context.Collector.SetStaticField(g_sensor_nextIdField, context.Collector.FromValue(value));

    return nullptr;
}

// Registration inside SHARDLIB_ENTRYPOINT:
// sensor.AddMethod(L"ResetCounter", TYPE_VOID, LINK_STATIC, ACS_PUBLIC)
//     .AddParameter(L"value", TYPE_INT)
//     .SetCallback(&sensor_resetCounter);
```

  **5. Store private native handles.**

  A private `TYPE_NINT` field is the standard pattern for wrapping OS resources, third-party
  library objects, or any pointer that ShardScript code should not see. Register it with
  `ACS_PRIVATE` and `LINK_INSTANCE`, then read it inside methods that
  operate on the resource.

```cpp
// Forward declaration of a callback defined elsewhere.
ObjectInstance* sensor_open(const CallState& context);

SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> devices(context, L"devices");

    devices.AddClass(L"Sensor", ACS_PUBLIC, LINK_INSTANCE, [](SymbolBuilder<ClassSymbol> sensor)
    {
        g_sensor_handleField = sensor.AddField(L"_handle", TYPE_NINT, LINK_INSTANCE, ACS_PRIVATE);

        sensor.AddMethod(L"Open", TYPE_VOID, LINK_INSTANCE, ACS_PUBLIC)
            .SetCallback(&sensor_open);
    });
}

static ObjectInstance* sensor_open(const CallState& context)
{
    ObjectInstance* self = context.Args[0];

    // In a real implementation this would be a real device pointer.
    void* nativeHandle = reinterpret_cast<void*>(0x1234);

    // isTransient = true: the GC must not try to free this pointer.
    self->SetField(g_sensor_handleField->SlotIndex, context.Collector.FromNint(nativeHandle, true));

    return nullptr;
}
```

<Warning title="Handle lifetime">
Set `isTransient = true` when the memory behind the handle is owned by the OS or by a
  third-party library. Set `isTransient = false` only when your native library allocated the
  memory and will free it explicitly, and you want the GC to participate in that cleanup.
</Warning>

  **6. Add backing fields for properties.**

  Properties registered with `AddProperty` can use a hidden field for storage. Call
  `AddBackingField()` on the property builder and keep the returned
  `FieldSymbol*`. The getter and setter callbacks then read and write that field just like
  any other instance field.

```cpp
static FieldSymbol* g_sensor_statusBacking = nullptr;

SHARDLIB_ENTRYPOINT
{
    SymbolBuilder<NamespaceSymbol> devices(context, L"devices");

    devices.AddClass(L"Sensor", ACS_PUBLIC, LINK_INSTANCE, [](SymbolBuilder<ClassSymbol> sensor)
    {
        SymbolBuilder<PropertySymbol> statusProp = sensor.AddProperty(L"Status", TYPE_STRING, LINK_INSTANCE, ACS_PUBLIC);
        g_sensor_statusBacking = statusProp.AddBackingField().Get();

        statusProp.AddGetter()
            .SetCallback([](const CallState& context)
            {
                ObjectInstance* self = context.Args[0];
                ObjectInstance* status = self->GetField(g_sensor_statusBacking->SlotIndex);

                if (status == nullptr || status == GarbageCollector::NullInstance)
                {
                    return context.Collector.FromValue(std::wstring(L"unknown"));
                }

                return status;
            })
            .AddSetter()
            .SetCallback([](const CallState& context)
            {
                ObjectInstance* self = context.Args[0];
                ObjectInstance* value = context.Args[1];

                // The setter validates the value before storing it.
                if (value == nullptr || value == GarbageCollector::NullInstance)
                {
                    self->SetField(g_sensor_statusBacking->SlotIndex, context.Collector.FromValue(std::wstring(L"unknown")));
                }
                else
                {
                    self->SetField(g_sensor_statusBacking->SlotIndex, value);
                }

                return nullptr;
            });
    });
}
```

<Info title="NullInstance is a valid object">
ShardScript `null` is represented by `GarbageCollector::NullInstance`,
  not by a C++ `nullptr`. Always check for both before dereferencing a reference-typed field.
</Info>

## Verification

  Build the shared library and load it from a ShardScript program. The program below creates two sensors, reads their
  ids, and exercises the property setter and getter.

// app.shard
```csharp
using stdio;
using devices;

namespace demo;

public static func Main() -> void
{
    a: Sensor = new Sensor();
    b: Sensor = new Sensor();

    // Each instance receives a unique id from the static _nextId field.
    println(a.Read());
    println(b.Read());

    // Static method that resets the shared counter.
    Sensor.ResetCounter(100);

    c: Sensor = new Sensor();
    println(c.Read());

    // Property backed by a private field.
    a.Status = "active";
    println(a.Status);
}
```

  Expected output when the synthetic handle is `0x1234` and the counter starts at
  `0`:

```text
4660
4661
4684
active
```

## Troubleshooting

  - **Crash when reading a field** — Verify you are using the field symbol returned by `AddField`, not a stale pointer from a previous registration. The `SlotIndex` is valid only for the type on which the field was registered.
  - **Static field value is shared across instances unexpectedly**  — That is the intended behavior. Move the data to an instance field if each object needs its own copy.
  - **Instance callback reads the wrong value** — Remember that  `context.Args[0]` is `this` for instance members. The first real parameter is at index `1`.
  - **Native handle is collected or freed by the GC** — Pass the correct `isTransient` flag to `Collector.FromNint`. Most external handles should be marked transient.
  - **Property getter returns null** — A backing field starts out as `GarbageCollector::NullInstance`. Provide a default value in the getter or initialize the field in the constructor.
  - **Static field write throws at runtime** —  `SetStaticField` rejects `nullptr`. Use  `GarbageCollector::NullInstance` or a boxed value instead.
